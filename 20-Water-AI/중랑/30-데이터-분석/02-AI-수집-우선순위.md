# AI 데이터 수집 우선순위

## 원칙

**수집 대상과 학습 Feature를 분리한다.** 상태/오류 Tag는 학습 입력으로 직접 쓰지 않더라도 품질 판정과 장애구간 제외를 위해 수집 가치가 있다.

| 우선순위 | 계통 | 수집 대상 | AI 활용 | 권장주기 | 현재 상태 |
|---|---|---|---|---|---|
| P0 | A2O `.20` | 설비별 유효전력, 누적전력량, PF, 전류/전압 보조 | 전력 예측·M&V·에너지 절감 | 5~10초 | XG5000/주소 확인 |
| P0 | A2 PILOT `.10` | DO/MLSS/ORP/pH, 유량/송풍량, RUN/FLT, Set Point | 공정상태·제약조건·전력 원인 설명 | 5~10초 | **원본 확보, Rule Book 기준화 중** |
| P0 | ETHERFOS | PV/NH4/NO3/PO4P 등 | 수질 Feature/Target | 분석기 갱신주기 고려 | Live 55 Tag 확인 |
| P0 | ETHERFOS 상태 | COMERR/FL/RN/MOD/MOD2 | 품질 Flag, 학습 제외구간 판정 | 동일 주기 | Live DB 확인 |
| P1 | A2O WQ 14 | COD/TN/TP/DOC/NH4/NO2/NO3/PO4/ORP/pH/DO/EC/Turb/Temp | 핵심 수질 후보 | 5~10초 | XG5000/SCADA 확인, 현재 Active DB에는 없음 |

## 개발 제안

1. **실제 장기 Historian/DB 위치와 보존기간을 먼저 확인**한다. 수집 HMI의 `junglang` SQL 연결실패가 확인된 상태다.
2. A2 PILOT `.10`은 원본을 확보했으므로 M203→M204→M102 순으로 [[../20-현장-시스템/07-A2-PILOT-PLC-Rule-Book|Rule Book]]을 기준화한다.
3. M203은 `DO → 운전모드 → 목표 DO/Hz 제어파라미터 → 실제 Hz → RUN/FAULT → 설비 kW` 체인을 P0로 묶어 Shadow Dataset을 만든다.
4. A2O `.20` Read-only Block Read PoC는 기존 SCADA/Logger를 방해하지 않는 조건에서 수행한다.
5. Raw DB에는 품질/시간/원천정보를 함께 저장하고, 학습에서는 품질 Flag로 고장·교정·통신이상 구간을 제외한다.
