# AI 데이터 수집 우선순위

## 원칙

**수집 대상과 학습 Feature를 분리한다.** 상태/오류 Tag는 학습 입력으로 직접 쓰지 않더라도 품질 판정과 장애구간 제외를 위해 수집 가치가 있다.

| 우선순위 | 계통 | 수집 대상 | AI 활용 | 권장주기 | 현재 상태 |
|---|---|---|---|---|---|
| P0 | A2O `.20` | 설비별 유효전력, 누적전력량, PF, 전류/전압 보조 | 전력 예측·M&V·에너지 절감 | 5~10초 | XG5000/주소 확인 |
| P0 | A2 PILOT `.10` | DO/MLSS/ORP/pH, 유량/송풍량, RUN/FLT, Set Point | 공정상태·제약조건·전력 원인 설명 | 5~10초 | A2 PILOT 원본 확보, M203 Rule 역분석 완료 |
| P0 | ETHERFOS | PV/NH4/NO3/PO4P 등 | 수질 Feature/Target | 분석기 갱신주기 고려 | Live 55 Tag 확인 |
| P0 | ETHERFOS 상태 | COMERR/FL/RN/MOD/MOD2 | 품질 Flag, 학습 제외구간 판정 | 동일 주기 | Live DB 확인 |
| P1 | A2O WQ 14 | COD/TN/TP/DOC/NH4/NO2/NO3/PO4/ORP/pH/DO/EC/Turb/Temp | 핵심 수질 후보 | 5~10초 | XG5000/SCADA 확인, 현재 Active DB에는 없음 |

## 개발 제안

1. **오프라인 AI는 신규 Collector를 기다리지 않는다.** 기존 장기 CIMON Logger를 Signal Master 기준으로 정규화해 M203 Dataset/Baseline부터 진행한다.
2. 신규 실시간 수집은 **A2 PILOT `.10` + A2O `.20` PLC Direct READ-only Collector**를 하나의 M203 대표신호 세트로 시험한다. A2 PILOT에서 공정/운전/Hz, A2O에서 M203 전력계 신호를 읽는다.
3. Collector 주소/Tag는 [[04-M203-Signal-Master-v0.9|M203 Signal Master]]에서 관리하고 코드에 별도 정본을 만들지 않는다.
4. Collector 가동 후 기존 SCADA/Logger와 겹침구간을 비교해 `PASS / SCALE / DELAY / AVG / MISMATCH / UNKNOWN`을 판정하고 Signal Master v1.0 승격 근거로 사용한다.
5. Raw/Canonical 공식 DB 방식은 공통 DB 설계안의 4인 검토 Gate를 따른다. Parquet/DuckDB는 오프라인 Batch·분석 작업공간으로만 사용한다.
6. AI 학습에서는 품질 Flag를 이용해 고장·교정·통신이상 구간을 제외한다.

> ETHERFOS 및 A2O WQ 14는 수질 Feature 후보로 유지하되, M203 1차 PoC의 선행 Gate는 Signal Master v0.9 QA/Freeze다.
