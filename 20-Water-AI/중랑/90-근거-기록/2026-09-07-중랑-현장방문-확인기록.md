# 2026-09-07 중랑 현장방문 확인기록

## 현재 확인된 것

2026-09-07 중랑 현장방문에서 다음을 직접 확인했다.

- 현장에서 확인한 PLC 통신은 **LS ELECTRIC XGT / FEnet 기반**이다.
- PLC 자체에는 과거 운전데이터를 별도로 장기 백업하고 있지 않다.
- 따라서 PLC는 실시간 현재값·상태·제어값의 원천으로 사용하되, 과거 AI 학습이력은 PLC 자체에서 확보하는 구조로 보면 안 된다.

## 기존 분석과의 관계

- 기존 중랑 분석에서 FEnet 기반 AI Data Agent 병렬 수집을 검토하고 있었으며, 이번 방문으로 **현장 PLC 통신이 XGT/FEnet 기반이라는 점은 직접 확인 수준으로 상향**한다.
- 기존 CIMON SCADA / Logger / SQL 구조 분석은 계속 유효하나, **실제 장기 보존기간과 누락 여부는 별도 확인이 필요**하다.

## 추가 확인 필요

- CIMON Logger의 실제 저장주기와 보존기간
- SQL/MariaDB의 실제 데이터 보존기간과 백업정책
- CSV Export 가능 범위와 기간
- FEnet 추가 Read-only 세션의 접속여유와 현장 승인조건
- **방문 시 복사한 PC 수집본 후속분석에서 A2 PILOT PLC 원본 확보를 확인함.** 상세 Sequence / Interlock / Run Permit / Timer / 최소·최대 Hz는 별도 Rule Book에서 기준화 중

## 개발에 미치는 영향

- AI 학습용 Master DB 구축 시 **PLC 실시간 수집**과 **기존 SCADA/Logger/DB 장기 이력 적재**를 별도 경로로 설계한다.
- PLC에 과거이력이 없으므로 장기간 학습데이터 확보 여부는 상위 저장계층의 보존정책에 좌우된다.
- AI는 기존 PLC/SCADA를 대체하지 않고 Read-only 수집 → Master DB → 예측/최적화 → SCADA/PLC 안전검증 구조를 유지한다.
