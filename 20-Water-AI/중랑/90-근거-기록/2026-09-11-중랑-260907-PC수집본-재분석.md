# 2026-09-11 중랑 260907 현장 PC 수집본 재분석

## 자료 범위

2026-09-07 중랑 현장 PC에서 확보한 `중랑물재생_260907` 수집본을 후속 분석한 기록이다. 현장 방문 당시 직접 본 사실과, 복사해 온 PC 파일을 나중에 해석해 확인한 사실을 구분하기 위해 별도 Source ID를 사용한다.

## 확정된 내용

- A2 PILOT XG5000 원본 `중랑처리장_A2O_Pilot_260508.xgwx`와 `.state`가 수집본에 존재한다.
- CIMON Device 설정에서 A2 PILOT PLC는 `192.168.90.10`, A2O PLC는 `192.168.90.20`으로 확인된다.
- A2 PILOT Project State에서 `Analog_Input`, `CONTROL_MAIN`, `VVVF_Control`, `VVVF_통신` 프로그램 구조와 `A_B_선택`, `교번운전`, `간헐운전`, `모터운전`, `유량제어` 등 Function Block/기능 항목을 확인했다.
- CIMON `A2 PILOT.PLC` 태그에서 M203 송풍기, M204 내부반송펌프, M102 유량조정펌프의 운전모드·Set Point·실제 Hz·RUN/FAULT·A/B 선택 주소가 확인된다.
- 수집본의 XLOG는 수질/전력 Raw History가 아니라 CIMON Runtime 진단 로그 성격이다.
- 2026-07-09~2026-09-07의 XLOG 61개 모두에서 `junglang 데이터베이스의 연결 실패 : 데이터 원본 이름이 없고 기본 드라이버를 지정하지 않았습니다.` 메시지가 확인되었다. 따라서 **이 PC에서 보이는 SQL 연결이 실제 장기이력 저장을 정상 수행했다고 가정할 수 없다.**
- 일보 파일은 2025-12-26~2026-09-07 구간에 다수 존재하고 월보도 존재하므로 보조 운전이력/대조자료로 활용 가능하다. 다만 AI 학습용 초·분 단위 Raw 시계열을 대신한다고 보지 않는다.

## 아직 확정하지 않은 것

- 실제 장기 Historian/DB 서버가 이 HMI PC인지, 별도 서버/PC인지
- `junglang` ODBC DSN의 정상 구성값, DB 서버 IP/DBMS, 실제 저장 테이블과 보존기간
- XG5000 Ladder의 각 접점 수준에서 M203/M204/M102의 최종 Run Permit, Interlock, 최대 Hz, Fault 대체운전 Sequence
- ORP가 M204 내부반송 제어에 직접 사용되는지 여부. ORP 값 자체는 존재하지만 현재 SCADA 제어태그는 MLSS 기반 운전이 명확하다.

## 프로젝트 영향

1. 기존 이슈였던 **“A2 PILOT 원본 미확보”는 해소**되어 PLC Rule Book 작성에 착수할 수 있다.
2. 반대로 **실제 장기 데이터 저장경로와 데이터 완전성 확인이 최우선 병목**으로 상승했다.
3. AI 개발은 M203을 1차 PoC로 하되, 먼저 `DO/운전모드/Set Point/실제 Hz/RUN·FAULT/설비전력`을 같은 시간축으로 확보해야 한다.
4. AI 권고값은 CIMON/A2 PILOT의 기존 안전 Rule을 경유하도록 설계한다.
