# 중랑 확정사항 기반 실행계획 · 2026-09-11

## 계획을 다시 잡는 이유

중랑은 이미 **장기 CIMON SCADA Logger 데이터(2025-09-24~2026-08-05)를 확보하고 샘플링·CLD↔CSV 검증까지 수행**했다. 9월 7일 PC 수집본으로는 **A2 PILOT 제어원본까지 확보**되었다. 따라서 현재는 데이터 부족 단계가 아니라, **장기 운전데이터와 PLC 제어원리를 연결하여 M203부터 학습 Dataset을 만드는 단계**다. `junglang` SQL 연결실패는 향후 실시간·지속 적재 경로를 확정하기 위한 별도 연계 이슈로 병행한다.

## 현재 단계

`장기 Logger 확보·샘플링` **완료** + `A2 PILOT 원본 확보` **완료** → `Signal Master/Rule Book 기준화` → `M203 Master Dataset` → `Baseline/예측·전력모델` → `M203 Shadow Mode` → `제약조건 기반 최적화` → `M204/M102 확대`

병행 과제: `운영 SQL/DB(junglang) 정상 연계 확인` → `실시간 Master DB 자동 적재`

## 중단 조건

- 확보한 장기 Logger 데이터에서 M203 필수 Tag의 기간·품질이 학습기준에 미달하면 해당 변수의 보완수집/대체 Feature 계획을 세운다. **운영 SQL/DB 확인 미완료 자체는 과거 Logger 기반 모델 개발의 중단조건이 아니다.**
- A2 PILOT Rule Book v1.0과 현장 승인 전에는 실제 자동제어를 수행하지 않는다.
- SCADA/PLC의 기존 안전 로직을 우회하는 인버터 직접제어는 기본안에서 제외한다.
