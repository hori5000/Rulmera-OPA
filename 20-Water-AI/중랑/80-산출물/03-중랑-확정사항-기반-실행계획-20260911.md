# 중랑 확정사항 기반 실행계획 · 2026-09-11

## 계획을 다시 잡는 이유

9월 7일 PC 수집본으로 **A2 PILOT 제어원본은 확보**되었다. 따라서 PLC Rule 분석은 더 이상 자료요청 대기항목이 아니다. 반면 CIMON Runtime에서 `junglang` SQL 연결실패가 반복된 사실이 확인되어, **실제 장기 Historian/DB의 위치·보존기간 검증이 AI 개발의 선행조건**이 되었다.

## 현재 단계

`구조 분석` **진행** → `데이터 저장경로 검증` **최우선** → `Signal Master/Rule Book 기준화` → `Master DB` → `M203 Shadow PoC` → `예측·전력모델` → `제약조건 기반 최적화`

## 2026-09-11 기준 내부 실행계획

| 기간(가안) | 해야 할 일 | 완료조건 | 연결 WBS |
|---|---|---|---|
| **9/11~9/15** | A2 PILOT Rule Book v0.9 작성, `junglang` 실제 DB/DSN/서버 경로 확인 | M203/M204/M102 제어항목표 + DB 위치/시간범위 확인 | 1.1.1, 1.1.2 |
| **9/15~9/18** | Signal Master v0.9 및 M203 E2E Chain 확정 | DO→모드→Set Point→실제 Hz→RUN/FAULT→kW가 같은 기준표에 연결 | 1.1.1, 2.2.1 |
| **9/21~9/25** | Master DB 샘플 적재·품질진단, M203 Shadow Dataset 생성 | Timestamp/결측/중복/Mode 구분 검증 + 학습용 Dataset 버전 고정 | 1.1.2, 2.1.1, 2.2.1 |
| **9/28~10/02** | **내부 PoC**: M203 설비전력 **머신러닝 회귀모델** Baseline + Shadow 권고 I/O | 운전 Hz/RUN 대수/유량/DO 등을 이용한 kW 예측 Baseline과 권고값 로그 생성 | 2.2.1~2.2.2 |
| **10월 이후** | 수질·공정상태 예측 + **제약조건 기반 제어·최적화 모델** | Rule 위반 없는 What-if/Shadow 시나리오 | 후속 AI/통합 WBS |

> 위 날짜는 **2026-09-06 가안 일정 안에서 중랑 우선순위를 다시 배열한 내부 실행기준**이며 계약 기준선 확정 시 변경로그로 재기준화한다.

## 우리가 제안하는 M203 PoC에서 먼저 묶을 최소 데이터

| 그룹 | 최소 항목 |
|---|---|
| 수질/공정 | DO, MLSS, ORP, 유입유량, 송풍량 |
| 제어 | 운전모드, 목표 DO, 시작 Hz, 제어폭, 제어주기, 최저 Hz, 실제 Hz |
| 상태 | RUN, FAULT, AUTO/MANUAL, A/B 선택, 가능한 Interlock/Permit |
| 전력 | M203 관련 설비 kW, 누적 kWh, 필요 시 전류/PF |
| 시간/품질 | sample_time, received_at, source, quality, 결측/통신이상 Flag |
| AI 이후 | 권고값, 승인/거부, 적용값, 모델버전, 명령 ID |

## 중단 조건

- 실제 장기 DB가 확인되지 않거나 학습기간이 부족하면 모델 학습 일정은 확정하지 않고 데이터 확보계획을 먼저 재수립한다.
- A2 PILOT Rule Book v1.0과 현장 승인 전에는 실제 자동제어를 수행하지 않는다.
- SCADA/PLC의 기존 안전 로직을 우회하는 인버터 직접제어는 기본안에서 제외한다.
