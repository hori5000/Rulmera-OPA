# 9.6 데이터 수집 모듈 개발 및 DB 적재 시험 실행계획

## 문서 목적

WBS 9.6 「데이터 수집 모듈 개발 및 DB 적재 시험」을 실제 구현 가능한 단위로 구체화한 실행계획이다. 목표는 중랑 Pilot Plant의 현장 데이터가 **독립 Read-only Collector를 통해 읽히고 DB에 저장되는 전 과정**을 검증하는 것이다.

## 추진 근거 및 현재 판단

### 자료에서 확인된 내용

- 연구개발계획서상 파이브텍 2차년도 개발내용은 Pilot Plant 물·에너지 최적화 모델 개발과 수처리 운영 최적화 통합 모델 연계 시스템 개발이다.
- 중랑 현행 분석에서 A2O PLC(`192.168.90.20`)는 계측·전력 수집 중심이며 CIMON SCADA와 SQL/Logger 저장 구조가 존재하는 것으로 정리되어 있다.

### 개발 제안

- 기존 SCADA/Logger를 대체하지 않고 **독립 Read-only Collector**를 병행 추가
- 주소와 의미가 확인된 10~20개 핵심 Tag부터 검증
- Local Buffer를 두어 DB/네트워크 장애 시 유실 방지
- Raw DB와 AI Master DB를 분리

## 1차 적용 범위

| 구분 | 실행 내용 |
|---|---|
| 우선 대상 | 중랑 A2O PLC `192.168.90.20` |
| 통신 | LS ELECTRIC XGT FEnet 전용통신 / TCP |
| 수집 Tag | 10~20개 핵심 Tag |
| 저장 | Local Buffer + 검증용 Raw DB |
| 검증 | SCADA 값 대조 + 장애복구 + 24시간 연속수집 |
| 제외 | PLC Write / 자동제어 / A2 PILOT Rule 수정 |

## Collector 구성

| 모듈 | 주요 기능 | 목적 |
|---|---|---|
| FEnet Adapter | TCP 연결, READ 요청/응답, 응답코드 처리 | PLC 직접수집 |
| Poll Scheduler | 설정주기 기반 Batch Read | 태그별 개별 연결 방지 |
| Tag Mapping | PLC 주소 ↔ 표준 Tag ID ↔ 단위/자료형 | 현장 차이를 코드와 분리 |
| Quality / Timestamp | 수신시각, 값 유효성, 품질코드 | AI 학습 품질 |
| Local Queue | 미전송 레코드 임시저장 | 장애 시 유실 방지 |
| DB Writer | Batch Insert, 중복방지, 재전송 | 안정적 적재 |
| Health / Log | 연결·수집·적재·재시도·오류 상태 | 운영 확인 |
| Test Console | PLC값/DB값/지연/누락/재시도 표시 | 현장 검증 |

## 통신 처리 원칙

- TCP Session을 유지하고 매 Tag마다 접속/해제를 반복하지 않는다.
- 동일 주기 Tag는 가능한 범위에서 Batch Read로 묶는다.
- Timeout/비정상 응답/범위오류는 값 보정이 아니라 `quality`로 기록한다.
- FEnet 상세 바이트 배열과 TCP Port/Channel/세션 여유는 현장 설정 확인 후 확정한다.

## 완료 기준

코드 존재만으로 완료하지 않는다. **실제 PLC 연결, Raw DB 적재, SCADA 값 대조, 장애복구, 24시간 연속수집 증빙**이 있어야 한다.

## 제외 범위

A2 PILOT Write/자동제어는 본 단계 완료조건에 포함하지 않는다.

## 추가 확인 필요

- FEnet Port/Channel/세션 여유
- Known Tag 주소·자료형·단위·스케일
- Collector 설치 PC의 PLC 네트워크 접근성
- 검증 DB Host/계정/Schema
- 현장 시험 가능 시간대
