# 현장별 원천 DB 설계안 선택현황

> 이 표는 **실제 구축팀이 선택하고 4인 검토 후 확정**한다. 아래 `권고`는 현재 분석자료를 기준으로 한 기술 제안이며 자동 승인된 결정이 아니다.

| 현장 | 분야 | 현재 Source 분석 수준 | 권고 | 실제 선택 | 선택사유 | 4인 확인 | 상태 |
|---|---|---|---|---|---|---|---|
| 중랑 | 하수 | 높음 — PLC/SCADA/Logger/DB 구조 다수 확인 | **A안** | 미선택 |  | 미완료 | 선택대기 |
| 용인 | 하수 | 낮음 — 실제 DB/Table 상세 미확보 | Source Inventory 후 결정 | 미선택 |  | 미완료 | 자료확인 필요 |
| 광암 | 정수 | 높음 — WWALMDB/Runtime/Historian/HMI Mapping 확인 | **A안** | 미선택 |  | 미완료 | 선택대기 |
| 명장 | 정수 | 낮음 — 현장 DB 상세 미확보 | Source Inventory 후 결정 | 미선택 |  | 미완료 | 자료확인 필요 |

## 선택 규칙

- `실제 선택`은 `A안` 또는 `B안`으로 기록한다.
- B안 선택 시 A안으로 전환할 시점/조건도 같이 기록한다.
- `4인 확인`은 김광민·홍효헌·정교석·윤석훈이 모두 검토한 후 `완료`로 변경한다.
- 구축이 시작된 뒤 Schema가 바뀌면 [[../../00-프로젝트관리/13-변경로그|변경로그]]에 남긴다.
