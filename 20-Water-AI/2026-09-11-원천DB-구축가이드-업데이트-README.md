# 2026-09-11 원천 데이터 DB 구축 가이드 업데이트

## 이번 변경의 목적

과제 연관기관이 참조할 실증지별 원천 데이터 DB를 코이넷이 실제로 설계·구축할 수 있도록, 현재 중랑·광암 분석결과를 기준으로 **두 가지 설계안과 현장별 적용 가이드**를 추가했다.

## 주요 변경

- 원천 DB 구축 수행조직을 **코이넷**으로 명시
- 김광민·홍효헌·정교석·윤석훈 **4인 검토 Gate** 정의
- A안: 원본 보존 + Canonical Master DB 분리형 **권고**
- B안: 원본 Replica + Mapping/View 중심형 **신속 이행안**
- 중랑·광암은 현재 확인된 실제 DB/Table/Logger/Historian을 링크로 제공
- 용인·명장은 실제 Source Inventory 전 임의 테이블 확정 금지
- 운영 Source DB는 읽기전용, 외부기관은 View/API를 통해 참조
- WBS/RACI/이슈/리스크/의사결정/변경/액션/기관 인터페이스 동시 반영
