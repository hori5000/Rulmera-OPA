# 2026-09-14 웹 변경팝업 적용안내

이번 마이그레이션 패키지는 Obsidian 전체를 덮어쓴 뒤 기존 **전체 게시(Publish)** 절차를 실행하면 웹 접속 시 2026-09-14 변경사항을 신규 Release popup으로 표시하도록 구성했다.

## Release 기준

- Release ID: `2026-09-14-m203-signal-master-migration-v8`
- Popup 주요 변경: 7건
- 기준 파일: `.web/release-update.json`
- `.web/update-state.json`은 **이전 Release ID**를 유지한다.

`update-state.json`을 미리 새 Release ID로 바꾸면 실제 게시 시 popup이 신규 변경으로 인식되지 않으므로 수동 수정하지 않는다.

## 게시 후 보일 핵심 변경

1. M203 Signal Master v0.9 신설
2. 과거 SCADA Logger와 신규 PLC Direct Collector 경로 분리
3. M203 Master Dataset v0.3
4. M203 실행순서·도구선정 기준 신설
5. PM/마일스톤/이슈/리스크/의사결정 정합화
6. Parquet/DuckDB와 공식 DB 결정 분리
7. Demo WBS 고객 Web 노출 제거 및 고객 진행현황 정리

## 게시 순서

1. 이 패키지의 `20-Water-AI`로 기존 Vault를 교체/병합한다.
2. 기존 `PUBLISH-RULMERA-OPA.ps1` 전체 게시 절차를 실행한다.
3. Water-AI 정적 Web이 재생성되어 `.web-public`이 교체되는지 확인한다.
4. Cloudflare Pages 배포 완료 후 고객 Web에 접속한다.
5. 신규 Release popup과 M203 Signal Master/실행순서 페이지를 확인한다.

> 기존 `.web-public`은 정적 산출물이므로 Markdown만 덮어써서는 자동으로 내용이 갱신되지 않는다. 반드시 기존 전체 게시 절차로 재생성한다.
