# OpenProject 연결

OpenProject에서 해당 화면을 연 뒤 브라우저 주소를 복사해 아래에 붙입니다. 저장된 보기를 삭제하거나 권한이 없으면 링크가 열리지 않을 수 있습니다.

| 대상         | 링크  | 용도         |
| ---------- | --- | ---------- |
| 프로젝트 홈     |     | 전체 현황      |
| 작업패키지 전체   |     | 업무 목록      |
| WBS 저장 보기  |     | 상하위 작업 구조  |
| 간트 저장 보기   |     | 일정과 의존관계   |
| 마일스톤 저장 보기 |     | 주요 완료 시점   |
| 내 작업       |     | 담당 업무      |
| 팀 플래너      |     | 담당자별 일정·부하 |
| 보드         |     | 상태별 업무 흐름  |

## 연결 규칙

- 개별 작업·이슈·위험·변경은 해당 작업패키지의 고유 주소를 문서에 기록합니다.
- WBS와 간트는 조건을 설정하고 **보기를 저장한 뒤** 주소를 사용합니다.
- OpenProject는 실행과 일정의 기준이며, Obsidian은 근거·판단·회의·지식의 기준입니다.
