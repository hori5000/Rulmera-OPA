## WBS 진행 현황

> [!info] Dataview 기본 쿼리만 사용
> 이 대시보드는 **Dataview JavaScript Queries가 꺼져 있어도** 표시되도록 구성했습니다. 자동 Mermaid Gantt([[20-WBS-Gantt-자동]])만 JavaScript Queries가 필요합니다.

```dataview
TABLE WITHOUT ID
  key AS "상태",
  length(rows) AS "WBS 수"
FROM "20-Water-AI/00-프로젝트관리/WBS"
WHERE level = 3
GROUP BY status
SORT key ASC
```

## 담당자별 WBS

```dataview
TABLE WITHOUT ID
```

## 마감 임박/지연 확인

```dataview
TABLE WITHOUT ID wbs AS "WBS", file.link AS "작업", assignee AS "담당", end AS "마감", status AS "상태", progress AS "진행률"
FROM "20-Water-AI/00-프로젝트관리/WBS"
```
