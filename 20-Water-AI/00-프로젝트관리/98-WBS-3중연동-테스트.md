# WBS 3중 연동 테스트

> [!warning] 이 테스트의 Mermaid 자동 생성은 `설정 → Dataview → Enable JavaScript Queries`가 **ON** 이어야 합니다.

이 페이지는 **Task Gantt → Markdown → Dataview + Mermaid** 연동을 눈으로 확인하는 테스트입니다.

## 1. Task Gantt에서 수정

`20-Water-AI/00-프로젝트관리/98-연동-예제` 폴더를 **Open as Gantt**로 엽니다.

예를 들어 `샘플-2 Baseline 구축`의 종료일을 9/18에서 9/22로 드래그해 보십시오.

## 2. 같은 원본을 Dataview가 읽는 표

```dataview
TABLE WITHOUT ID
  file.link AS "작업",
  start AS "시작",
  end AS "종료",
  status AS "상태",
  progress AS "진행률"
FROM "20-Water-AI/00-프로젝트관리/98-연동-예제"
SORT start ASC
```

## 3. 같은 원본을 Mermaid Gantt로 자동 표시

```dataviewjs
const ps = dv.pages('"20-Water-AI/00-프로젝트관리/98-연동-예제"')
  .where(p => p.start && p.end)
  .sort(p => p.start)
  .array();

function fd(v) {
  if (typeof v?.toFormat === "function") return v.toFormat("yyyy-MM-dd");
  return String(v).substring(0, 10);
}
function clean(s) {
  return String(s).replace(/[,:#;]/g, " ").replace(/\s+/g, " ").trim();
}

let lines = [
  "gantt",
  "    title 단일 원본 연동 예제",
  "    dateFormat YYYY-MM-DD",
  "    axisFormat %m/%d",
  "    section 예제"
];

for (let i = 0; i < ps.length; i++) {
  const p = ps[i];
  let flag = p.status === "done" ? "done, " : (p.status === "in-progress" ? "active, " : "");
  lines.push(`    ${clean(p.title ?? p.file.name)} :${flag}demo_${i+1}, ${fd(p.start)}, ${fd(p.end)}`);
}

dv.paragraph("```mermaid\n" + lines.join("\n") + "\n```");
```

### 확인할 것

Task Gantt에서 날짜/진행률/상태를 바꾸면 작업 Markdown의 frontmatter가 바뀝니다. 이 페이지의 Dataview 표와 Mermaid는 그 같은 frontmatter를 다시 읽기 때문에 별도 복사 없이 따라 바뀝니다.
