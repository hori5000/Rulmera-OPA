# 2026-09-14 M203 기준선 및 실행순서 마이그레이션

이번 마이그레이션은 현재 Obsidian 전체 문서를 다시 대조하여 **이미 확보된 자료를 미확보로 표시한 오래된 문구와 M203 작업순서 충돌을 정리**한 것이다.

## 핵심 변경

- A2 PILOT XG5000 원본은 이미 확보된 상태로 전 문서 정합화
- 장기 CIMON Logger는 이미 확보된 상태로 유지
- M203 Signal Master v0.9 신규 기준문서 + 기존 Mapping CSV 확장
- MLSS/ORP, M203 전력 PLC 주소, AO_OP_SEL1/2/3 등 누락 매핑 보강
- Timer 진행값 `%MW176/177` vs SCADA `%MW1012/1013`는 주소계층을 분리하고 추가확인으로 관리
- Rule Book Open Item을 정확히 5개로 통일
- 전체 CLD Batch보다 Signal Master QA/Freeze를 먼저 수행하도록 PM/마일스톤/액션 정렬
- 신규 실시간 경로는 A2 PILOT/A2O PLC Direct READ-only Collector로 정리
- 기존 SCADA/Logger/MySQL은 과거이력/교차검증 경로로 분리
- Parquet/DuckDB는 로컬 분석도구이며 공식 원천 DB 결정과 분리
- Replay Simulator Framework는 병행 개발, 실제 Replay는 동일 Dataset version 사용
- WBS Demo 문서(D.1~D.3)를 웹 공개 대상에서 제외
- 9/7·9/11 근거기록은 당시 사실을 보존하되 9/14 후속 결정(PLC Direct Collector, 현재 Rule Open 5개)을 명시
- CIMON `junglang` SQL 이슈는 AI Source 선택문제가 아니라 Legacy DB 위치·적재·과거 Set Point/Mode 확인 문제로 범위 정정
- Timer 진행값은 Signal Master에서 `부분확정-주소계층관계Open`으로 통일
- 웹 Release Update를 2026-09-14 기준으로 갱신
- 전체 QA 결과는 [[2026-09-14-Obsidian-마이그레이션-QA]] 참조
