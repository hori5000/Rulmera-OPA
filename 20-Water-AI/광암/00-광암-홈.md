## 정수 AI 개발 원칙

광암은 **정수 AI 학습·검증 기준 시설**이다.

```text
광암정수장 장기 운전데이터
→ Historian/기존 저장계층 확인
→ AI Master DB
→ 정수 수요·수질·약품·전력 분석
→ 정수 AI 예측/최적화 모델 개발
→ 모델 검증 및 표준화
→ 명장 최종 적용장에 적용
```

PLC 자체에 과거이력이 없으므로 실제 학습데이터는 **Wonderware Historian 등 상위 저장계층에서 확보**해야 한다. 실시간 보완이 필요한 경우에만 기존 PLC 통신에 영향이 없도록 별도 Read-only Collector를 검토한다.

## 2026-09-09 POS11 `Runtime.dbo.History` 실조회 사진 확인 — v8

현장 SSMS 사진에서 다음이 직접 확인됐다.

- SQL Server 노드: **`POS11`**
- 선택 Database: **`Runtime`**
- Object Explorer에 `A2ALMDB / Holding / ReportServer / ReportServerTempDB / Runtime / WWALMDB` 존재
- 쿼리에서 `FROM History`
- Historian 전용 조회조건:
  - `wwRetrievalMode = 'Cyclic'`
  - `wwCycleCount = 100`
  - `wwQualityRule = 'Extended'`
  - `wwVersion = 'Latest'`
- 조회 Tag: `PCS5_HV1A_2_TA`
- 결과 Grid에서 `TagName / DateTime / vValue / MinRaw / MaxRaw / MinEU / MaxEU / Unit / Quality`가 실제 반환됨

따라서 다음은 **확정**으로 올린다.

> **광암 POS11의 Wonderware Historian은 `Runtime.dbo.History` SQL 조회 인터페이스를 통해 실제 공정 시계열 값을 조회할 수 있다.**

다만 사진만으로 실제 장기 값이 저장된 물리 파일의 정확한 위치를 확정할 수는 없다. `D:\Historian\Data\Circular / Buffer / Permanent`는 기존 Historian Export/설정 근거와 일치하므로 **실제 History Storage 후보 경로**로 유지하되, 현재 서버의 `StorageLocation.Path` 또는 파일시스템으로 최종 확인한다.

AI 관점 상태는 다음과 같이 수정한다.

```text
실시간/과거 Historian 값 존재 및 SQL 조회 가능 = 확인
Runtime BAK에 장기 값 본체 포함              = 아님
장기간 AI 학습용 데이터 우리 측 인수          = 아직 미완료
다음 작업                                      = POS11 History 장기 Export
```

## 2026-09-09 Historian 원본 확보 전략 — v9

현장 작업시간이 짧다는 제약을 반영하여, AI 학습데이터 확보 순서를 **장기 SQL Export 우선**에서 **History Storage 위치/용량 확인 → 원본 인수 가능성 판단**으로 변경한다.

```text
POS11
  ↓
Runtime.dbo.StorageLocation / StorageNode 확인
  ↓
실제 History Storage Path 확인
  ↓
PowerShell로 총 GB/TB + 파일수 + 드라이브 여유공간 측정
  ↓
┌ 용량 감당 가능 → History Storage 원본 인수 검토
└ 용량 과다/운영복사 곤란 → History SQL 월별 Export
```

### 현재 판단

- **자료로 확인됨**: POS11 `Runtime.dbo.History`에서 실제 공정 시계열 값 조회 가능. Runtime DB에 `StorageLocation`, `StorageNode` 객체가 존재하며 2022 Historian Export에는 `D:\Historian\Data\Circular / Buffer / Permanent` 경로 근거가 있음.
- **합리적 추정**: 현재 POS11의 실제 장기 공정값은 Runtime SQL BAK 자체가 아니라 Historian History Storage 파일영역에 저장되어 있을 가능성이 높음.
- **추가 확인 필요**: 2026 현재 `StorageLocation.Path` 실제값, 해당 폴더 총용량, 파일수, 최초/최종 보존기간, 운영 중 원본 복제 방식.
- **주의**: 운영 중인 Historian Storage를 단순히 서비스 중지하거나 강제 복사하지 않는다. 서비스 중지는 현장 승인/운영영향 확인 후에만 검토한다.
