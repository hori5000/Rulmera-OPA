# Water AI · 광암

## 현재 상태

- **현장 확인**: 2026-09-07 현장방문 완료
- **PLC 통신**: 현장에서 확인한 PLC 통신은 **LS ELECTRIC XGT / FEnet 기반**
- **PLC 과거이력**: PLC 자체 장기 백업 없음
- **자료 수집 상태**: 통신방식은 확인했으나 HMI/SCADA/Logger/DB의 장기이력 저장 위치·보존기간·Export 방법은 추가 확인 필요
- **학습 데이터 상태**: 실제 장기간 광암 운전데이터의 기간·주기·결측률 확인 전
- **모델 검증 상태**: 데이터 확보상태 확인 전이므로 모델 검증 미착수
- **다음 작업**: 장기 운전이력 저장계층 확인 → Tag/PLC 주소 Mapping → 샘플 데이터 확보 → 품질진단 → Master DB 설계

## 정수 AI 개발 원칙

광암은 **정수 AI 학습·검증 기준 시설**이다.

```text
광암정수장 장기 운전데이터
→ Master DB
→ 정수 수요·수질·약품·전력 분석
→ 정수 AI 예측/최적화 모델 개발
→ 모델 검증 및 표준화
→ 부산 명장정수장 최종 적용
```

PLC 자체에 과거이력이 없으므로 실제 학습데이터는 **HMI/SCADA/Logger/DB 등 상위 저장계층에서 확보**해야 한다.
