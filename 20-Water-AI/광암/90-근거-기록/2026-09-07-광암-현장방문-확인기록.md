# 2026-09-07 광암 현장방문 확인기록

## 현재 확인된 것

2026-09-07 광암 현장방문에서 다음을 직접 확인했다.

- 현장에서 확인한 PLC 통신은 **LS ELECTRIC XGT / FEnet 기반**이다.
- PLC 자체에는 과거 운전데이터를 별도로 장기 백업하고 있지 않다.
- 광암은 정수 AI 학습·검증 기준 시설이므로, 실제 장기 운전이력 확보 경로를 우선 확정해야 한다.

## 추가 확인 필요

- HMI/SCADA/Logger/DB 중 실제 장기 이력을 저장하는 계층
- 데이터 보존기간
- 저장주기와 Timestamp 기준
- 원수/정수량, 탁도, 약품, 펌프 Hz/가동대수, 설비별 전력, Set Point, AUTO/MANUAL, Alarm/Fault의 실제 Tag Mapping
- 과거 이력 Export 방법과 제공 가능한 기간
- FEnet Read-only Collector 추가 접속 가능조건

## 개발에 미치는 영향

- 광암 AI 학습데이터를 PLC 내부 백업에서 확보한다는 전제는 사용하지 않는다.
- 정수 AI Master DB는 **장기 HMI/SCADA/DB 이력 + 필요 시 FEnet 실시간 수집**을 결합하는 방향으로 설계한다.
- AI 기법 최종 선정 전에 실제 확보 가능한 데이터 기간·주기·결측률을 먼저 확인한다.
- 광암에서 학습·검증한 정수 AI 구조를 표준화한 뒤 명장 최종 적용장에 적용하는 개발 원칙은 유지한다.

## 2026-09-08 후속 자료분석 연결

현장방문 이후 확보한 `Wonderware.zip` 분석에서 다음이 추가 확인되었다. 아래 내용은 **현장 직접확인 사항이 아니라 후속 자료분석 결과**로 구분한다.

- Wonderware InTouch HMI 2014 R2 SP1 (v11.1)
- Wonderware Historian Server 2014 R2 SP1 (v11.6.13100)
- DeviceXPlorer 5.4.0.1 설정 파일 `DXPSV.dxp`
- `LsisEthernet` Device 13개 및 원격 TCP Port 2004
- FSGateway 3.0 SP1 구성요소 존재. 단 실제 운전 경로 사용 여부는 미확정
- 기존 `WWALMDB`는 Historian이 아니라 InTouch Alarm DB 계열로 분류
