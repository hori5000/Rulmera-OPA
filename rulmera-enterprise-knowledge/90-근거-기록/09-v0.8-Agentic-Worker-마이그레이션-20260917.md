# v0.8 Agentic Worker 마이그레이션 기록

## 목적
기존 Rulmera OPA는 Knowledge OPA와 Continuous Ingestion 중심이었다. 이번 마이그레이션에서 **Qwen이 권한이 허용된 작업을 Worker에 지시하고 결과를 회수하는 Action OPA / Agentic Execution 구조**를 정식 제품 범위로 추가했다.

## 핵심 결정
- Qwen은 직접 OS/shell을 실행하지 않는다.
- 실행 전 OPA Action Authorization을 통과한다.
- Worker Controller가 Job을 검증·배차·상태관리한다.
- Worker는 제한된 Tool/Workspace에서 실제 작업한다.
- Git은 필수 인프라가 아니라 선택적 Source/Job/Audit Adapter다.
- 기존 `ingestion-worker`와 새 `execution-worker`를 분리한다.
- Job/Result Contract와 실행 감사이력을 정식 규격으로 둔다.
