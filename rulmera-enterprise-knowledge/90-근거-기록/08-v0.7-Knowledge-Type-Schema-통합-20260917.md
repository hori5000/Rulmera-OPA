# v0.7 Knowledge Type Schema 통합 기록

> [!summary]
> Obsidian Template을 단순 편의 양식으로 두지 않고, 향후 Rulmera Manager와 Rulmera Knowledge Studio가 공통으로 사용할 정식 Knowledge Type 규격을 프로젝트에 통합했다.

## 추가 내용
- 6개 Knowledge Type 정식 정의
- Type별 필수/선택 필드
- AI 자동생성 규칙
- 관리자 검토 규칙
- 승인 상태전이 규칙
- Obsidian Template과 정식 Schema 연결

## 원칙
**Obsidian은 초기 검증 도구이고, Rulmera Knowledge Schema가 장기 제품 자산이다.**
