## 기획안에서 프로젝트 기준선으로 채택한 원칙
- Identity → Policy(OPA) → Retrieval → LLM
- LLM이 보안을 판단하지 않는다.
- L0~L5 보안등급 + 실제 업무/프로젝트 맥락
- 숙련자의 말도 검토/승인 후 정본화
- 같은 자료도 전문수준 K0~K4에 따라 설명방식을 조정
- 기업별 Tenant/저장소/Policy 격리
- Private LLM / On-Prem 우선
- 사실은 RAG, 습관은 Fine-tuning
- 모든 답변에 근거/출처, 충돌 시 최신 승인본 우선
- 질문/검색/다운로드/DENY 감사
- 한 기업 PoC → 다기업 패키지 확산

## 초기 PoC 규모와 제품화 연결
기획안은 본 PoC를 1~3만 문서, 20~50명 규모로 제시하지만, 본 개발계획은 기술위험을 더 빨리 줄이기 위해 **그 전에 100~300문서 / 10일 Vertical Slice**를 별도로 둔다. Vertical Slice 통과 후 1~3만 문서 규모로 확장한다.
