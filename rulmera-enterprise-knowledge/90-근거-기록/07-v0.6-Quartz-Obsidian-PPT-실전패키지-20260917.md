# v0.6 Quartz·Obsidian·PPT 실전패키지 기록

> [!summary]
> v0.5 스타일 기준을 실제 적용 가능한 Quartz SCSS, Obsidian Templates/Templater, PowerPoint 1장 아키텍처 산출물로 구체화했다.

## 수행 내용
1. Quartz v5 `quartz/styles/custom.scss` 실전 배치 구조 추가
2. Obsidian 기본 Templates 6종 추가
3. Templater 자동화 Templates 6종 추가
4. PPT 1장 아키텍처 초안 Markdown 추가
5. 실제 PowerPoint 파일 생성 후 `80-산출물`과 `99-첨부`에 포함
6. 산출물 목록 갱신

## 설계 원칙
- Rulmera Knowledge Schema를 기준으로 삼는다.
- 편집도구와 Web Renderer는 교체 가능한 부품으로 둔다.
- 승인 전 지식은 사용자와 RAG에 노출하지 않는다.
- 원문 Web 링크와 AI 답변은 같은 권한체계를 사용한다.
