## 이번에 통합한 결정

### A. Rulmera Template + Qwen
- Qwen은 Rulmera Template을 변경하지 않는다.
- Qwen은 HTML 화면 대신 Answer Contract를 반환한다.
- Rulmera가 UI/보안 Badge/Citation/Deep Link를 렌더링한다.

### B. Voice + Evidence
- 음성은 STT를 거쳐 텍스트와 동일한 OPA/RAG 경로 사용.
- 답변 근거는 logical resource ID를 통해 실제 원문 위치로 연결.

### C. Continuous Knowledge
- 신규/변경/삭제 파일 자동 감지
- AI Metadata/보안/버전/프로젝트 후보
- Project Candidate
- 고위험 사람승인
- 증분 Chunk/Embedding/Index
- 새 사실은 반복 Qwen 재학습보다 RAG 갱신

### D. Deployment Fabric
- One Rulmera Release
- Cloudflare / On-Prem / Customer Cloud Profile
- 동일 UI/API/Logical Route
- PostgreSQL+pgvector Core 유지
- S3-compatible Object Adapter
- `workerd`는 선택적 Workers-compatible runtime
- Cloudflare 전체 Edge/CDN/DDoS 복제는 범위 밖
- Parity test를 릴리즈 품질 Gate로 추가
