# v0.5 전수 스타일 정리 기록 v0.5

> [!summary]
> 전체 문서 전수 동일 스타일 재정리, Quartz/Obsidian 표시 기준 정리, PPT 도식 스타일 통일 작업을 기록한다.

## 수행 항목
1. 전체 Markdown 문서에 공통 스타일 메타데이터 적용
2. 제목 버전을 v0.5로 통일
3. 문서 상단에 요약/표기 기준 블록 추가
4. Mermaid 도식에 공통 컬러 테마 적용
5. Quartz용 CSS 기준 문서 추가
6. Obsidian CSS Snippet 추가
7. PPT 도식 스타일 가이드 추가
8. 스타일 시스템 전용 폴더 `95-스타일-시스템` 신설

## 결과
- 전체 문서가 공통 문서 스타일을 따르도록 정리됨
- Quartz/Obsidian/PPT 공통 시각 기준 확보
- 비전문가도 읽기 쉽도록 용어 기준 링크 상단 고정

## 비고
- Quartz 실제 배포 저장소에서는 `95-스타일-시스템/06-Quartz-Custom-CSS.md`의 CSS 내용을 실제 스타일 파일로 옮겨 적용하면 된다.
- Obsidian에서는 `.obsidian/snippets/rulmera-opa-enterprise.css`를 바로 사용할 수 있다.
