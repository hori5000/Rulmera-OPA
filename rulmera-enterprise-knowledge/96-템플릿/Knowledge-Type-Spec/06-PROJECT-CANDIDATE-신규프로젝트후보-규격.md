# PROJECT_CANDIDATE — Project Candidate(신규 프로젝트 후보) 규격 v0.7

> [!summary]
> 기존 Project Master에 없는 새로운 업무·고객·제품·설비 문맥이 반복 발견될 때 AI가 프로젝트 생성 여부를 관리자에게 묻기 위한 후보 규격이다.

## 필수 항목
- 추정 프로젝트명
- 최초 발견 자료 목록
- 발견 근거
- 기존 프로젝트와의 유사도/차이
- 추정 고객사
- 추정부서
- 보안등급 후보
- AI confidence(판단 신뢰도)
- `candidate_status`

## 관리자 결정
- 신규 프로젝트 생성
- 기존 프로젝트에 연결
- 보류
- 잘못된 후보

## AI 자동생성 규칙
1. 폴더명만으로 신규 프로젝트를 확정하지 않는다.
2. 문서 내용, 고객사, 설비, 일정, 참여자, 프로젝트 코드 등을 종합한다.
3. 기존 프로젝트와 높은 유사도가 있으면 병합 후보를 먼저 제시한다.
4. 신규 프로젝트 생성 시 기본 Template 구조를 제안할 수 있다.
5. AI는 최종 `project_id`를 직접 발급하지 않는다.
