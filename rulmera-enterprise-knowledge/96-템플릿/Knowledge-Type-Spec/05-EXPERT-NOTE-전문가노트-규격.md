# EXPERT_NOTE — Expert Note(전문가 노트) 규격 v0.7

> [!summary]
> 숙련자가 실제 현장에서 사용하는 판단순서, 예외처리, 실수방지 요령 등 암묵지(Tacit Knowledge)를 회사 지식으로 전환한다.

## 필수 항목
- 적용 상황
- 숙련자의 판단 순서
- 공식 매뉴얼과 다른 점 또는 보완점
- 자주 하는 실수
- 사실 확인이 필요한 부분
- 전문가/출처
- `project_id`
- `security_level`
- `approval_status`

## 선택 항목
- 적용 설비
- 적용 조건
- 예외 상황
- 관련 장애사례
- 인터뷰 원문

## AI 자동생성 규칙
1. 전문가 발언을 자동으로 `정답` 처리하지 않는다.
2. 사실, 경험적 판단, 추정을 구분한다.
3. 숫자·한계값·작업순서는 검증 필요 여부를 표시한다.
4. 기존 매뉴얼과 충돌하면 Conflict Candidate(충돌 후보)를 생성한다.
5. 승인 전에는 RAG 정본으로 사용하지 않는다.
