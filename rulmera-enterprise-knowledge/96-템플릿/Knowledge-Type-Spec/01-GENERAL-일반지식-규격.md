# GENERAL — General Knowledge(일반 지식) 규격 v0.7

> [!summary]
> 매뉴얼, 표준절차, 기술 설명, 제품·설비 설명처럼 반복 활용되는 일반 지식을 정본화한다.

## 필수 항목
- 제목
- 개요
- 핵심 내용
- `tenant_id`
- `project_id` 또는 프로젝트 미지정 사유
- `security_level` 후보/확정값
- `approval_status`
- `source_uri`
- `revision`
- `owner`

## 선택 항목
- 설비/제품 ID
- 적용 대상 부서
- 적용 업무
- 유효기간
- 관련 고객사/NDA
- 관련 문서
- 주의사항

## AI 자동생성 규칙
1. 원문에서 제목·목차·반복 키워드를 추출한다.
2. 기존 Project Master와 비교해 프로젝트 후보를 제안한다.
3. 문서의 목적을 한두 문장으로 요약한다.
4. 절차 문서이면 순서를 유지한다.
5. 숫자·조건·파라미터는 원문 근거 위치와 함께 보존한다.
6. 출처가 불명확한 내용을 보완 추정하지 않는다.

## 승인 체크
- 최신 버전인가?
- 원문과 요약이 충돌하지 않는가?
- 보안등급이 적절한가?
- 폐기된 절차가 섞이지 않았는가?
