# DECISION — Decision Record(의사결정 기록) 규격 v0.7

> [!summary]
> 왜 특정 기술·부품·설계·업무방식을 선택했는지와 검토한 대안을 남겨 이후 변경 이유를 추적할 수 있게 한다.

## 필수 항목
- 결정할 문제
- 선택한 방안
- 선택 이유
- 검토한 대안
- 영향 범위
- 결정일
- 의사결정자/승인자
- `project_id`
- `security_level`
- 근거 자료

## 선택 항목
- 비용 영향
- 일정 영향
- 리스크
- 되돌리기 조건
- 재검토 예정일

## AI 자동생성 규칙
1. 회의록이나 이메일에서 `결정`, `확정`, `채택`, `보류`, `제외` 문장을 탐지한다.
2. 단순 의견과 최종 결정을 구분한다.
3. 선택 이유와 제외 이유를 서로 분리한다.
4. 승인자가 불명확하면 자동 확정하지 않는다.

## 승인 체크
- 실제 최종 결정인가?
- 대안과 제외 이유가 왜곡되지 않았는가?
- 영향받는 문서/설계의 후속 변경이 연결됐는가?
