# 10영업일 Vertical Slice PoC — 가장 빠른 검증안

## 목표
**10일 안에 “문서를 넣으면 → 권한을 확인하고 → 허용된 문서만 찾아 → Qwen이 근거와 함께 답하고 → Windows/Android 크기에서 같은 UI로 보이는 것”을 끝까지 시연한다.**

## 왜 이게 가장 빠른가
- 고객 전체 데이터 1~3만 문서를 기다리지 않는다.
- 관리자 기능을 완성하기 전에 Chat/Policy/RAG 핵심 위험을 검증한다.
- 7~14B 모델로 plumbing을 먼저 통과시키고 20~30B 품질모델로 교체한다.
- Frontend는 첫 주부터 만들어 Windows와 Android viewport에서 동시에 확인한다.

## PoC 데이터가 없을 때 바로 시작하는 방법
의도적으로 아래 자료를 만든다.
- L0 공개 카탈로그 20개
- L1 일반 매뉴얼 20개
- L2 부서 문서 20개
- L3 기술/소스 20개
- L4 핵심 Recipe/알고리즘 10개
- L5 고객원가/NDA 가상문서 10개
- 동일 주제 Rev.1/Rev.2 충돌 10쌍

**보안 시험은 실제 기밀이 없어도 먼저 검증할 수 있다.** 이후 실제 고객 데이터를 같은 스키마로 교체한다.

## PoC 최종 화면
- 로그인 사용자/인가 Lx 표시
- 질문 입력
- Streaming 답변
- 근거 1~N개
- 근거 클릭→문서/버전/위치
- 권한 없음은 명확한 DENY 메시지
- 관리자: 오늘 질문/DENY/승인대기 요약
