# 기술스택 결정 초안 v0.5

> [!summary]
> 이 문서는 구현 순서, 개발 범위, 기술 적용 계획을 정리한 개발 기준 문서다.

> [!info]
> 표기 기준: 전문 용어는 가능하면 `원어(알기 쉬운 설명)` 형식을 사용하고, 공통 기준은 [[20-설계/00-용어-스타일-가이드]]를 따른다.

| 영역 | 1차 선택 | 이유 | 교체/Adapter |
|---|---|---|---|
| Frontend | React + TypeScript + Vite | 단일 UI/빠른 개발 | 낮음 |
| PWA | Vite PWA | 설치형 Web | 낮음 |
| Android | Capacitor | Build 재사용 | 낮음 |
| Backend | FastAPI | AI/Python 생태계 | 낮음 |
| Auth | Adapter | Local→OIDC/LDAP | 높음 |
| Policy | Open Policy Agent | 외부화된 RBAC+ABAC | 낮음 |
| DB | PostgreSQL | 공통 Core DB | 낮음 |
| Vector | pgvector | PoC 단순화 | Qdrant 등 가능 |
| Object | S3-compatible Contract | R2/MinIO/고객S3 | 높음 |
| LLM | Qwen 20~30B급 | 한국어/Private | 모델 Adapter |
| LLM Output | Versioned Answer Contract | UI 안정성 | 모델 무관 |
| Voice | STT Adapter | Browser/Private STT 교체 | 높음 |
| Ingestion | Watcher + Job Queue | 지속 갱신 | Connector 확장 |
| Deployment | Manifest + Profiles | Build Once Deploy Anywhere | 환경 Adapter |
| Cloudflare | Workers + Static Assets Adapter | Edge/Web 배포 | 선택 |
| On-Prem Web | Nginx/Caddy/Traefik 후보 | Private | 선택 |
| Workers-compatible local | workerd 후보 | 선택적 self-host | 필수 아님 |
| Container | Docker Compose | PoC | 운영 K8s 가능 |
