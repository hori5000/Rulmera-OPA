# 기술스택 결정 초안

| 영역 | 1차 선택 | 이유 | 교체 가능성 |
|---|---|---|---|
| Frontend | React + TypeScript + Vite | 빠른 HMR/단일 UI | 낮음 |
| UI | Responsive CSS + Component system | desktop/mobile 공용 | 낮음 |
| PWA | Vite PWA | 설치형 Web/오프라인 shell | 낮음 |
| Android | Capacitor | Web build 재사용 | 낮음 |
| Backend | FastAPI | AI/Python 생태계, 빠른 API | 낮음 |
| Auth | PoC JWT Adapter | 빠른 검증 | OIDC/LDAP로 확장 |
| Policy | Open Policy Agent | RBAC+ABAC 외부화 | 낮음 |
| DB | PostgreSQL | 범용/신뢰성 | 낮음 |
| Vector | pgvector | PoC 구성요소 최소 | 규모확대 시 Qdrant 등 |
| Object | Local -> MinIO | On-Prem | 낮음 |
| LLM | Qwen 20~30B급 | 한국어/업무/로컬 배치 | 벤치 결과로 모델변경 가능 |
| Model serving | vLLM/SGLang/llama.cpp 후보 | GPU/양자화별 실측 | 높음 |
| Embedding | 다국어 임베딩 모델 | 한국어+영문 기술문서 | 벤치로 확정 |
| Reranker | Cross-encoder 계열 | 검색정밀도 | 벤치로 확정 |
| Deployment | Docker Compose | PoC 단순화 | 운영시 K8s 선택 가능 |
