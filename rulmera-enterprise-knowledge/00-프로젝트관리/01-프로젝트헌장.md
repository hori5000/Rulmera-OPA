# 프로젝트 헌장

## 1. 프로젝트명
**Rulmera OPA Enterprise Knowledge**

## 2. 총괄 및 핵심 역할
- 프로젝트 총괄/PM/제품책임자: **룰메라팀 윤석훈 팀장**
- 개발: **윤석훈 팀장 — AI/RAG, Backend, Frontend, OPA/보안, DB, 인프라, 시험, Android 패키징을 포함한 개발 전 과정**
- 마케팅·영업: **룰메라팀 김일형 / 코이넷 대표**
- PoC 고객 기술책임자: 미정

## 3. 목적
기술중소기업의 문서·설계·소스·매뉴얼·장애이력과 숙련자의 암묵지를 회사 지식으로 정본화하고, 사용자 인가에 따라 허용된 지식만 검색하여 **근거와 함께 답하는 사내 AI 선임자**를 제품화한다.

## 4. 배경
- 기술자료가 개인 PC·메일·파일서버 등에 흩어져 있고 최신본 판별이 어렵다.
- 실제 장애해결·판단순서·예외처리 같은 핵심 지식은 문서화되지 않는 경우가 많다.
- 퇴사·이동 시 숙련자의 경험이 조직에서 사라진다.
- 일반 LLM에 기밀자료를 직접 전달하는 방식은 기업 보안 요구에 맞지 않는다.
- 단순 문서검색이 아니라 **권한·승인·감사·정본화**가 포함된 Enterprise Knowledge 운영체계가 필요하다.

## 5. 목표
1. 질문 전에 OPA가 사용자의 회사/부서/업무/프로젝트/인가를 판정한다.
2. L0~L5 자료등급과 RBAC+ABAC를 조합해 금지자료를 Retrieval 단계에서 차단한다.
3. 승인된 정본만 RAG 검색 대상으로 사용하고 답변에는 출처·버전·충돌정보를 붙인다.
4. 숙련자 Q&A·장애사례·설계판단을 후보지식으로 수집해 검토·승인 후 정본화한다.
5. A6000 48GB급 단일 GPU에서 동작 가능한 Private Qwen-class LLM PoC를 구현한다.
6. Windows 브라우저와 Android에서 동일 코드베이스로 자연스럽게 동작하는 Responsive UI를 구현한다.
7. 10영업일 내 Vertical Slice PoC로 기술·보안·UI를 먼저 검증하고, 전체 제품화는 약 6개월을 목표로 한다.

## 6. 범위
### 포함
- Knowledge ingestion: PDF/DOCX/PPTX/XLSX/CSV/Markdown/TXT/소스코드/이미지 기반 자료의 단계적 수집
- 문서 메타데이터: tenant, 보안등급, 부서, 프로젝트, 담당자, 버전, 승인상태, 유효기간, 출처
- RAG: Chunking, Embedding, Vector Search, Reranking, Context Assembly, Citation
- 정책: Open Policy Agent 기반 RBAC+ABAC, L0~L5, 프로젝트/NDA/기간 조건
- 사용자/Identity: PoC 로컬계정 후 AD/LDAP/OIDC 연계 가능 구조
- Private LLM: A6000 기반 Qwen 20~30B급 또는 동급 모델
- 지식 승인 Workflow, Expert Notes, 충돌/구버전 경고
- 질의/검색/다운로드/DENY 감사로그
- 기업별 Tenant 격리 구조
- Responsive Web Client + PWA + Android Capacitor 패키징
- 관리자 화면: Knowledge Health, 승인대기, 권한, 감사
- PoC 평가셋과 자동 회귀시험

### 제외/후순위
- 1차 PoC에서 대규모 Fine-tuning
- iOS Native App
- 고객사 ERP/MES/PLM/SCADA 등 모든 시스템과의 즉시 실시간 연계
- HA 클러스터/다중 GPU 대규모 서비스 구성
- 완전 자동 지식승인 — 승인 책임은 사람에게 둔다.

## 7. 성공기준
- 권한 위반/금지자료 노출: **0건**
- 문서 근거가 필요한 답변의 출처 표시율: **100%**
- 50문항 PoC 평가에서 전문가 기준 유용 답변: **80% 이상**을 초기 목표로 측정
- 근거 없음 질문에서 추측 대신 모름/추가자료 요청: **90% 이상**
- 구버전/충돌 문서 시험에서 경고 및 최신 승인본 우선 동작 확인
- 360px 모바일, 768px 태블릿, 1440px 데스크톱에서 핵심 질의 기능 사용 가능
- Web/PWA/Android가 **하나의 Frontend 코드베이스**를 공유
- PoC 종료 시 고객 데모 가능한 End-to-End 흐름 확보
