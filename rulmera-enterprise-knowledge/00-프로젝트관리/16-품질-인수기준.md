# 품질·인수기준

| 산출물/기능 | 품질기준 | 시험/검증방법 | 인수조건 | 상태 |
|---|---|---|---|---|
| RAG 답변 | 근거문서와 일치, 근거 밖 추측 억제 | 50문항 Golden Set | 유용답변 80%+ 초기목표 | 계획 |
| 출처 표시 | 문서답변에 문서/버전/위치 표시 | Citation 자동/수동 검사 | 적용대상 100% | 계획 |
| OPA 권한 | DENY 자료가 검색/Context/답변에 포함되지 않음 | L0~L5 사용자 × 문서 매트릭스 | 권한위반 0건 | 계획 |
| Tenant 격리 | A회사 질문으로 B회사 자료 검색 불가 | 교차 Tenant 공격시험 | 0건 | 계획 |
| 승인 Workflow | 후보→검토→승인→정본 전환 | 상태전이 시험 | 승인전 RAG 미사용 | 계획 |
| 문서 버전 | 최신 승인본 우선, 충돌 경고 | Rev 충돌 시나리오 | 최신본 우선+경고 | 계획 |
| 감사로그 | 질의/검색/다운로드/DENY 추적 | 로그 재현 | 사용자/시간/대상/결과 기록 | 계획 |
| Responsive UI | 360/768/1440px 핵심기능 사용 가능 | Browser devtools + Android 실기기 | 기능누락/가로스크롤 없음 | 계획 |
| Web/Android 공통 | 동일 frontend build 사용 | 빌드 artifact 비교 | 별도 화면 코드 없음 | 계획 |
| 성능 | PoC 표준질의 median 15초 내 초기목표 | 20회 반복계측 | 목표 또는 원인/개선안 기록 | 계획 |
| 복구 | DB/문서/정책 복구 가능 | Restore drill | 문서화된 절차로 복구 | 계획 |
