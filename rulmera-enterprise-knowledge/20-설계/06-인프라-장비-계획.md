# 인프라·장비·예산 계획 v0.5

> [!summary]
> 이 문서는 제품 구조, 데이터 흐름, 권한 구조, 동작 원리를 설명하는 설계 기준 문서다.

> [!info]
> 표기 기준: 전문 용어는 가능하면 `원어(알기 쉬운 설명)` 형식을 사용하고, 공통 기준은 [[20-설계/00-용어-스타일-가이드]]를 따른다.

## 1. PoC 기준 장비
### 권장 최소
- GPU: NVIDIA RTX A6000 48GB
- CPU: 12~16 Core 이상 권장
- RAM: **128GB 이상**
- NVMe: **4TB 이상** — 모델/원본/Index/DB/캐시 분리 고려
- Network: 1GbE 가능, 다수 사용자/대용량 원본이면 10GbE 권장
- UPS: 2kVA급 권장
- Backup: 별도 NAS/외장 스토리지

## 2. 모델 선택 주의
A6000은 48GB VRAM이 장점이지만 **Ampere 세대**다. Qwen3.8-27B 공식 FP8 파일은 약 30.9GB로 작지만, Ampere는 Hopper와 달리 FP8 Tensor Core가 기본 대상이 아니다. 따라서 **파일이 VRAM에 들어간다는 이유만으로 FP8을 기본선택하지 않는다.**

### PoC 순서
1. 7~14B급 모델로 API/UI/RAG plumbing을 즉시 확인
2. Qwen 20~30B급을 A6000 친화 INT4/AWQ/GPTQ 구성으로 시험
3. Context 8K/16K/32K 별 VRAM/속도 계측
4. Reranker/Embedding 동시사용 시 VRAM 압박 확인
5. 결과로 최종 serving runtime 확정

## 4. 예산 시나리오
### A. 기존 A6000 장비를 재사용
- GPU: 0원
- RAM/NVMe/UPS/Network/Backup 보강: **약 300~700만원 계획범위**
- 가장 경제적인 PoC 경로

### B. A6000 GPU만 신규 구매 + 본체 구성
- GPU 840~1,200만원
- 본체/메모리/스토리지/UPS/백업 300~700만원
- **약 1,140~1,900만원** 계획범위

### C. 중고 A6000 + 본체 구성
- GPU 600~780만원
- 기타 300~700만원
- **약 900~1,480만원** 계획범위

## 5. 구매 결정 Gate
PoC 종료까지 신규 GPU 구매를 서두르지 않는다. 다음 중 하나면 업그레이드 검토:
- 목표 20~30B 모델이 A6000에서 실사용 latency를 만족하지 못함
- 동시사용자 목표가 단일 A6000 처리량을 초과
- 48GB VRAM이 context/멀티모달/동시 rerank 때문에 지속적으로 부족
