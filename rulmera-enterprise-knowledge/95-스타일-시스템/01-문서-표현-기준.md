# 문서 표현 기준 v0.5

> [!summary]
> 이 문서는 문서 표현, 도식 스타일, CSS 적용 기준을 통일하기 위한 스타일 시스템 문서다.

> [!info]
> 표기 기준: 전문 용어는 가능하면 `원어(알기 쉬운 설명)` 형식을 사용하고, 공통 기준은 [[20-설계/00-용어-스타일-가이드]]를 따른다.

## 1. 제목 규칙
- 문서 제목은 `# 문서명 v0.5` 형식 사용.
- 버전이 올라가면 변경로그 또는 근거기록 문서에 같이 남긴다.

## 2. 요약 규칙
- 문서 맨 위에 `> [!summary]` 블록을 둔다.
- 요약은 “이 문서가 무엇을 정하는가”를 한두 문장으로 말한다.

## 3. 용어 규칙
- 처음 등장하는 전문 용어는 `원어(알기 쉬운 설명)` 형식 권장.
- 약어만 단독으로 남기지 않는다.
- 공통 용어는 [[20-설계/00-용어-스타일-가이드]] 기준 사용.

## 4. 도식 규칙
- Mermaid 도식은 공통 테마를 적용한다.
- 사람/화면/사용자 흐름 = 파랑 계열
- 정책/승인/절차 = 주황 계열
- 저장/지식/허용 상태 = 초록 계열
- 차단/오류/주의 = 빨강 계열
- 배포/환경/외곽요소 = 보라 또는 회색 계열

## 5. PPT 정렬 규칙
- 박스 내부 텍스트는 2~3줄 내로 제한한다.
- 한 슬라이드 기준 박스 깊이는 4단계를 넘기지 않는다.
- 동일 수준 박스는 같은 색상 계열을 사용한다.
