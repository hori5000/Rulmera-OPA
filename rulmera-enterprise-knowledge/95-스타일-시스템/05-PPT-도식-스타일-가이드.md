# PPT 도식 스타일 가이드 v0.5

> [!summary]
> 이 문서는 문서 표현, 도식 스타일, CSS 적용 기준을 통일하기 위한 스타일 시스템 문서다.

> [!info]
> 표기 기준: 전문 용어는 가능하면 `원어(알기 쉬운 설명)` 형식을 사용하고, 공통 기준은 [[20-설계/00-용어-스타일-가이드]]를 따른다.

## 컬러 팔레트
| 역할 | 색상 | 용도 |
|---|---|---|
| Primary Blue | `#2F80ED` | 사용자, 화면, 주요 흐름 |
| Secondary Green | `#27AE60` | 승인된 지식, 성공 상태 |
| Accent Orange | `#F2994A` | 정책, 승인, 절차 |
| Alert Red | `#EB5757` | 차단, 오류, 경고 |
| Deploy Purple | `#6C5CE7` | 배포환경, 외곽 시스템 |
| Neutral Gray | `#64748B` | 연결선, 보조 박스 |

## 박스 스타일
- 모서리: 둥근 사각형 우선
- 선 굵기: 1.5~2.25pt
- 내부 여백: 충분히 확보
- 그림자: 약하게만 사용
- 본문 글꼴: 맑은 고딕 또는 Noto Sans KR 계열

## 텍스트 규칙
- 제목: 한글 중심 + 필요 시 영문 병기
- 전문 용어: `원어(쉬운 설명)`
- 박스당 핵심 메시지 1개

## 레이아웃 규칙
- 좌→우 흐름 또는 상→하 흐름 하나만 선택
- 같은 레벨 박스는 같은 너비 우선
- 선이 교차하지 않도록 그룹별 간격 확보
