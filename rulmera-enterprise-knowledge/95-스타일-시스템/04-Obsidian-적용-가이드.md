# Obsidian 적용 가이드 v0.5

> [!summary]
> 이 문서는 문서 표현, 도식 스타일, CSS 적용 기준을 통일하기 위한 스타일 시스템 문서다.

> [!info]
> 표기 기준: 전문 용어는 가능하면 `원어(알기 쉬운 설명)` 형식을 사용하고, 공통 기준은 [[20-설계/00-용어-스타일-가이드]]를 따른다.

## 적용 파일
- CSS Snippet: [[95-스타일-시스템/07-Obsidian-CSS-Snippet]]
- 공통 용어: [[20-설계/00-용어-스타일-가이드]]

## 적용 방법
1. `.obsidian/snippets/` 폴더에 CSS 파일 저장
2. Obsidian 설정 → 모양(Appearance) → CSS Snippets에서 활성화
3. Mermaid 기본 렌더와 충돌이 없는지 확인

## 기대 효과
- 콜아웃, 표, 코드블록, Mermaid 시각 일관성 확보
- Quartz와 비슷한 시각 인상 유지
