# Rulmera 배포 프로파일 표준

## 목적

환경별 설치 스크립트가 제품의 동작을 바꾸지 않게 한다.

## Manifest 개념

```yaml
rulmera:
  release: v0.3

deployment:
  profile: cloudflare | onprem | customer-cloud
  base_url: https://...

routes:
  api: /api
  knowledge: /knowledge
  assets: /

database:
  type: postgres
  dsn_ref: secret:RULMERA_DB_DSN

object:
  adapter: s3
  endpoint_ref: secret:RULMERA_OBJECT_ENDPOINT
  bucket: rulmera-knowledge

identity:
  adapter: local | oidc | ldap

ai:
  adapter: private-qwen
  endpoint_ref: secret:RULMERA_LLM_ENDPOINT

voice:
  stt_adapter: browser | private-stt | disabled
```
