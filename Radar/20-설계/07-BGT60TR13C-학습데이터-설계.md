# BGT60TR13C 학습 데이터 / Library 활용 설계

기준일: 2026-09-16

## 1. 목적
확정된 Radar MMIC **Infineon BGT60TR13C**와 공급 예정 **AS_613 4대**를 기준으로, 어떤 데이터를 수집하고 Infineon/인지니어스 Library의 어떤 기능을 이용해 AI 학습 입력을 만들지 정한다.

핵심 원칙은 다음과 같다.

> **Raw ADC 자체가 목표가 아니다. 제품 문제를 가장 잘 설명하는 안정적인 Feature를 확보하는 것이 목표다.**

따라서 학습은 `Target → Intermediate DSP → Raw ADC` 순으로 깊게 들어간다.

---

## 2. BGT60TR13C 데이터 구조 이해

### Sensor 구조
- 1 Tx
- 3 Rx
- 60 GHz FMCW
- 3개 Rx가 L자 배열이라 각도 추정에 유리
- 각 Rx는 **Real IF ADC sample** 출력
- 직접 I/Q 두 채널을 내보내지 않음

### Raw frame 개념
```text
Frame
 └─ Rx[3]
     └─ Chirp[Nc]
         └─ Sample[Ns]
```

예를 들어:
```text
[3 Rx] × [64 chirps] × [128 samples]
```

실제 차원은 Radar config에 따라 달라진다.

## 3. Library / SDK에서 기대할 기능

### A. Device / Acquisition Layer
확인 대상:
- Device enumerate
- Sensor type / board UUID
- Get/Set FMCW config
- Start/stop acquisition
- Get next raw frame
- Register/config export
- Recording / replay

현재 Infineon RDK 계열의 실무 API/예:
- Python `ifxradarsdk.fmcw.DeviceFmcw`
- Python `DeviceFmcw.get_list()` / `device.get_next_frame()`
- Python `get_version_full()`
- C/C++ `ifx_fmcw_get_next_raw_frame(...)` 계열
- 구 Avian API/예제에서는 `ifx_avian_get_next_frame(...)`가 사용됨
- Range-Angle Image 계열 C API 예: `ifx_rai_run_r(...)`
- 과거/참고 Angle Capon API: `ifx_anglecapon_run(...)`
- Python 예제: `examples/py/BGT60TR13C/range_angle_map.py`

버전에 따라 API 이름이 바뀔 수 있으므로 공급 AS_613 Library와 RDK의 함수명을 1:1 Mapping한다.

### B. Range Processing
기능:
- Window
- Range FFT
- Range Spectrum
- Peak / distance estimation

학습용:
- target range
- peak magnitude
- peak width
- local clutter 대비 peak ratio
- range profile local patch

### C. Doppler Processing
기능:
- Slow-time FFT
- Range-Doppler map
- radial velocity

학습용:
- target velocity
- RD local patch
- 움직임 방향/일관성
- micro-motion energy
- 정적 Ghost vs 실제 움직임 분리

### D. Angle / Beamforming
기능:
- 3Rx phase relation
- Digital Beamforming(DBF)
- Range-Angle map
- Capon 계열 angle spectrum 가능

학습용:
- angle peak
- angle spread
- 다중 peak 수
- peak sharpness
- Rx pair phase consistency
- 주변 반사 peak 구조

### E. Detection / Segmentation / Presence
Infineon Radar SDK에는 presence/segmentation 계열 예제·알고리즘이 제공된다.

학습용:
- vendor detection 결과와 자체 detection 비교
- occupancy/zone feature
- target candidate quality feature

## 4. 실제 학습에 사용할 우선순위

### Stage 1 — Target-only Baseline
AS_613에서 바로 받을 가능성이 가장 높은 데이터로 시작한다.

입력:
```text
x,y,z
velocity
confidence/SNR
size
target_id
track history
sensor_id
wall distance
sensor agreement
```

학습 문제:
1. Ghost / Real 분류
2. Track confidence
3. Cross-radar association
4. Merge/Split 판정

장점:
- 빠름
- 데이터량 작음
- Edge 이관 쉬움
- AS_613 API가 제한적이어도 진행 가능

### Stage 2 — Intermediate DSP Feature
Raw ADC 또는 SDK intermediate 결과가 확보되면 추가한다.

권장 입력:
```text
range_peak
range_peak_width
rd_patch
rd_peak_velocity
ra_patch
angle_peak
angle_spread
rx_phase_diff_12
rx_phase_diff_13
rx_phase_diff_23
snr_or_power
noise_floor
clutter_residual
```

이 단계가 **실제 제품 AI의 핵심 후보**다.

이유:
- Raw보다 훨씬 작음
- 물리 의미가 분명함
- Ghost/반사/Merge 문제와 직접 연결됨
- Edge에서 재현하기 쉬움

### Stage 3 — Raw ADC Temporal Model
다음 조건일 때만 진행한다.
- Stage 2보다 성능 개선 여지가 명확함
- 충분한 라벨 확보
- Radar config를 고정할 수 있음
- Edge 연산량/메모리 예산을 감당 가능

후보:
- 1D CNN
- 작은 2D CNN on chirp×sample
- Temporal CNN
- Tiny Transformer는 마지막 후보

## 5. 4 Radar 학습 데이터 설계

### R01~R04 고정
샘플 입고 즉시:
```text
R01
R02
R03
R04
```
를 부여한다.

각 Radar마다:
- Serial
- PCB Rev
- Host MCU
- FW version
- SDK/Library version
- 설치 위치
- yaw/pitch/roll
- config hash
를 고정 기록한다.

### 공통 타임라인
```text
T
├─ R01 frame/raw/target
├─ R02 frame/raw/target
├─ R03 frame/raw/target
└─ R04 frame/raw/target
```

하드웨어 Sync가 없으면:
1. Host receive timestamp
2. per-device frame sequence
3. buffering
4. 시간 offset 추정
을 이용한다.

### 간섭 데이터도 학습셋으로 보존
- R01 only
- R01+R02
- 4 Radar all-on
- 프레임 시작 시각 stagger
- 설정 차등

간섭 발생 여부 자체를 로그에 label로 남긴다.

## 8. 첫 번째 AI 실험 Matrix

| 실험 | 입력 | 목적 |
|---|---|---|
| A0 | Rule only | 기준선 |
| A1 | Target history | Ghost/Track quality |
| A2 | Target + multi-radar agreement | Fusion 개선 |
| A3 | A2 + Range/Doppler feature | 움직임/반사 분리 |
| A4 | A3 + Range-Angle/Capon feature | 벽반사/근접분리 |
| A5 | Raw ADC model | 최종 연구, 필요 시 |

A5가 A4를 유의미하게 이기지 못하면 Raw model은 제품에 넣지 않는다.

## 9. 학습에 쓰지 말아야 할 항목
다음은 모델 입력보다는 QA/Domain 관리용으로 우선 사용한다.

- SDK version

- USB latency
