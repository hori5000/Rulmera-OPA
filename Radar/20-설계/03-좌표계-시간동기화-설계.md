# 좌표계·시간동기화 설계

## 좌표계
각 레이더는 자신의 Local 좌표를 갖고, Rulmera는 공통 `Room Coordinate`를 정의한다.

```text
p_room = R_sensor_to_room * p_sensor + t_sensor_to_room
```

센서별로 다음을 보관한다.
- 위치 x,y,z
- yaw / pitch / roll
- Calibration version
- 설치 Jig/실측 근거

## 설치 후보
- 4개 Sensor
- 방위 약 90° 간격
- 하향 약 45° 후보

이는 초기 Jig 값일 뿐이며, 실제 Coverage/오차 시험 후 Freeze한다.

## Calibration 절차 후보
1. 설치 Pose 실측
2. 기준 Target을 Room의 여러 알려진 점에 배치
3. 센서별 관측 좌표 기록
4. Extrinsic matrix 최적화
5. Test point로 검증
6. matrix version 저장

## 시간 정합
최선: Radar HW timestamp + common trigger  
차선: Radar 내부 timestamp  
기본: Host 수신 timestamp + latency/skew 보정

## 버퍼 방식
센서 Frame을 짧은 Time Window에 모으고 가장 가까운 시각끼리 Fusion한다. 센서 1개가 늦으면 전체를 무조건 멈추지 말고 일정 Timeout 후 가용 센서만 사용한다.

## 측정할 지표
- sensor별 frame interval
- host receive jitter
- inter-sensor skew
- dropped frame
- serial/USB buffering latency
