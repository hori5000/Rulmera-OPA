# 데이터 로깅 / Replay 도구

## 기본 원칙
샘플 4대는 입고 즉시 `R01~R04`로 고정 ID를 부여한다. 모든 로그는 Target-level만 저장하지 말고 **AS_613가 허용하는 가장 낮은 Data Level까지 함께 저장**한다.

## 세션 폴더 예시
```text
session_20260916_183000/
  session.json
  config/
    R01_config.json
    R02_config.json
    R03_config.json
    R04_config.json
  raw/
    R01_adc.bin           # Raw ADC 가능 시
    R02_adc.bin
    R03_adc.bin
    R04_adc.bin
  intermediate/
    R01_rd.bin            # Range-Doppler 가능 시
    R01_ra.bin            # Range-Angle/Capon 가능 시
  target/
    R01_targets.jsonl
    R02_targets.jsonl
    R03_targets.jsonl
    R04_targets.jsonl
  ground_truth.csv
  notes.md
```

## session.json 필수
- date/time
- 장소/Room ID
- sensor serial / R01~R04
- PCB revision
- host MCU
- firmware
- sdk/library
- settings/config hash
- sensor pose
- PC clock
- operator
- test scenario
- active sensor count
- interference test mode
- logger version

## BGT60TR13C Raw 메타
Raw ADC가 가능하면 아래를 반드시 함께 저장한다.
- array shape: `[rx][chirp][sample]`
- rx_mask / tx_mask
- start/end frequency
- sample rate
- chirps per frame
- samples per chirp
- chirp repetition
- frame repetition
- IF gain
- TX power
- ADC normalization/scale 설명
- frame counter가 있으면 원본 유지

## Replay 기능
- 1x / 0.5x / step
- 특정 센서 mute
- 특정 Data Level 선택
- 지연/jitter 삽입
- frame drop 삽입
- 같은 입력으로 알고리즘 버전 비교
- 1/2/4 Radar 간섭 시나리오 Replay
- Raw → DSP → Target 단계별 결과 비교
