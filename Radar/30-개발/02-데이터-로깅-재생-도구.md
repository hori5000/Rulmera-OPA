# 데이터 로깅 / Replay 도구

## 세션 폴더 예시
```text
session_20260915_183000/
  session.json
  radar_01.raw
  radar_01.parsed.jsonl
  radar_02.raw
  radar_02.parsed.jsonl
  radar_03.raw
  radar_03.parsed.jsonl
  radar_04.raw
  radar_04.parsed.jsonl
  ground_truth.csv
  notes.md
```

## session.json 필수
- date/time
- 장소/Room ID
- sensor serial
- firmware
- sdk/library
- settings
- sensor pose
- PC clock
- operator
- test scenario

## Replay 기능
- 1x / 0.5x / step
- 특정 센서 mute
- 지연/jitter 삽입
- frame drop 삽입
- 같은 입력으로 알고리즘 버전 비교
