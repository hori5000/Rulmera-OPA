# AI 학습 데이터 요구사항

## 필수 데이터

| 구분 | 요구 데이터 | 필수 이유 |
|---|---|---|
| L0 | RX별 Raw ADC / Raw Radar Frame | 모든 후속 알고리즘을 다시 적용할 수 있는 원본 |
| Config | Radar 설정값 | 물리적 거리/속도/해상도 재현 |
| Time | Timestamp + Frame counter | 외부 정답 및 센서간 동기화 |
| QA | Drop/Overflow/Error | 손상 프레임 제거 및 품질관리 |
| Label | Ground Truth | 감독학습 정답 |
| Meta | 설치 높이/각도/방향/환경/세션 | 환경 변화 일반화 |
| Version | Firmware/Library/Profile version | 데이터 계보 및 재현성 |

## Radar Configuration 최소 항목

- 활성 TX/RX
- 시작/종료 또는 중심 주파수와 대역폭
- Samples per chirp
- Chirps per frame
- ADC sample rate
- Chirp timing
- Frame period / frame rate
- Gain / 관련 analog baseband 설정
- Radar power/profile
- 데이터 배열 순서 및 dtype

## Label 최소 구조

```text
session_id
trial_id
subject_id(익명)
event
event_start_timestamp
event_end_timestamp
ground_truth_source
confidence(optional)
```

## 원칙

- Label과 Feature를 동일 필드에 섞지 않는다.
- 업체 알고리즘의 낙상/재실/생체 판정은 Ground Truth가 아니라 **Benchmark/Weak Label**로 별도 보존한다.
- 사람의 실제 행동/외부 센서/동기화 영상 등 독립 Ground Truth를 우선한다.
