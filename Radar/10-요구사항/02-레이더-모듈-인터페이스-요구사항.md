# 레이더 모듈 인터페이스 요구사항

## 최소 필요 데이터
Low-level 데이터가 없더라도 아래만 확보되면 Target-level MVP를 시작한다.

```text
sensor_id
host_rx_timestamp
frame_id           # 제공 시
radar_timestamp    # 제공 시
target_id          # 제공 시
x, y, z
velocity           # 제공 시
size/extent        # 제공 시
snr/confidence     # 제공 시
status/flags       # 제공 시
radar_setting_snapshot
firmware_version
```

## 권장 Common Frame
```text
RadarFrame
 ├─ sensor_id
 ├─ frame_seq
 ├─ radar_ts
 ├─ host_rx_ts
 ├─ pose_id
 ├─ config_id
 └─ targets[]
      ├─ vendor_target_id
      ├─ position_local[x,y,z]
      ├─ velocity_local
      ├─ size
      ├─ confidence
      └─ raw_fields
```

## 데이터 레벨 우선순위
1. Target 좌표 — 반드시 필요
2. Confidence/SNR/Velocity — 강하게 권장
3. Detection Point — 가능하면 확보
4. Angle/Capon Grid — 가능하면 확보
5. Range-Doppler — 연구 확장
6. Raw ADC/IQ — 연구/독자 신호처리 확장

## 버전 식별
로그 시작 시 반드시 다음을 저장한다.
- AS_613 serial/sensor id
- FW version
- SDK/Library version
- 설정값
- 설치 Pose
- 전원/통신 방식
