# 레이더 모듈 인터페이스 요구사항

## 확정 Sensor
- MMIC: **Infineon BGT60TR13C**
- 1Tx / 3Rx
- Raw sensor data: Rx별 **Real IF ADC sample**
- 직접 I/Q pair 출력 방식으로 가정하지 않는다.

## 최소 필요 데이터
Low-level 데이터가 없더라도 아래만 확보되면 Target-level MVP를 시작한다.

```text

radar_timestamp    # 제공 시

x, y, z

status/flags       # 제공 시

```

## 권장 Common Frame
```text
RadarFrame

      ├─ vendor_target_id

      ├─ velocity_local
      ├─ size
      ├─ confidence
      └─ raw_fields
```

## 데이터 레벨 우선순위
1. Target 좌표 — 반드시 필요
2. Confidence/SNR/Velocity — 강하게 권장
3. Detection Point / Peak list — 가능하면 확보
4. Range-Angle / Capon / Beam response — 가능하면 확보
5. Range-Doppler / Range Spectrum — 학습 성능 향상 후보
6. **Raw ADC / Real IF [Rx, chirp, sample]** — 독자 DSP/학습 확장

> `Raw IQ`를 별도 필수항목으로 두지 않는다. BGT60TR13C는 Rx별 Real IF를 출력하며 FFT 결과의 complex spectrum/phase를 후처리에서 사용한다.

## 버전 식별
로그 시작 시 반드시 다음을 저장한다.
- AS_613 serial/sensor id
- PCB revision
- Host MCU
- FW version
- SDK/Library version
- 설정값 전체
- 설치 Pose
- 전원/통신 방식
- PC Logger version
