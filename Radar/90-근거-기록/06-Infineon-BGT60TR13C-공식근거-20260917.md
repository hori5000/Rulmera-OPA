# Infineon BGT60TR13C 공식 근거

## BGT60TR13C Datasheet

확인 사항:

- 60 GHz FMCW Radar
- 1 TX / 3 RX
- RX-IF를 샘플링하는 3개 ADC 채널
- 12-bit ADC, 최대 4 MSps
- Raw data transfer를 위한 FIFO
- SPI configuration/status interface
- IRQ / RST
- 외부 기준 clock 사용

공식 문서:
- https://www.infineon.com/assets/row/public/documents/24/49/infineon-bgt60tr13c-datasheet-en.pdf

## Real IF

Infineon 기술지원 설명 기준으로 BGT60TR13C는 native I/Q pair 대신 **real IF**를 출력한다.
real IF를 FFT 처리하면 각 주파수 성분에 대한 복소 스펙트럼과 위상 정보를 사용할 수 있다.

참고:
- https://community.infineon.com/t5/Radar-sensors/BGT60TR13C-ADC-FIFO-control/td-p/379913

## 개발 방향에 대한 의미

공식 키트는 Rulmera가 직접 PSoC 6 firmware를 작성하여 BGT60TR13C를 제어하는 PoC에 적합하다.
단, PC용 Raw streaming bridge는 Rulmera에서 별도로 설계/구현하고 실제 전송 대역폭을 검증한다.
