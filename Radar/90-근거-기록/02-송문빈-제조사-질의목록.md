# 송문빈 대표 / 인지니어스 기술 질의목록

## 최우선 P0
1. AS_613 안에 실제로 들어간 Infineon Radar 칩 정확한 모델명이 무엇인가?
2. 현재 샘플 펌웨어 버전은 무엇인가?
3. 이 펌웨어가 AS_613 AI User Manual v2.2와 정확히 맞는가?
4. PC용 SDK 또는 라이브러리의 정확한 이름/버전은 무엇인가?
5. Header/API 문서와 샘플코드를 받을 수 있는가?
6. 현재 상위 프로그램이 받는 가장 낮은 데이터 레벨은 무엇인가?
   - Target 좌표
   - Detection Point
   - Angle/Capon Grid
   - Range-Doppler
   - Raw IQ/ADC
7. `op=0/1/2`의 Capon/Grid 결과를 프로그램에서 배열 형태로 직접 받을 수 있는가, 아니면 내부 계산 결과 좌표만 나오는가?
8. x/y/z 외에 velocity, size, SNR, confidence, quality, target id가 있는가?
9. 각 Frame에 radar timestamp/frame number가 있는가?
10. 외부 Trigger 또는 여러 모듈 Sync 기능이 있는가?
11. 4개를 가까이 동시에 켰을 때 레이더끼리 간섭하지 않는가? 권장 배치/설정이 있는가?
12. UART와 USB 각각 실제 최대 output rate는 얼마인가?
13. 샘플 4개 이상을 동시에 테스트할 수 있게 공급 가능한가?
14. SDK/Library를 Rulmera 제품에 포함해 배포 가능한 라이선스인가?

## 답변 후 바로 바뀌는 설계
- Raw/Intermediate data 가능 → Lower-level Fusion/AI branch 활성화
- Timestamp/Sync 가능 → Hardware-aligned Fusion
- Target only → Target-level Fusion을 제품 기준으로 Freeze
- 10 Hz 고정 → Tracker prediction 비중 증가
