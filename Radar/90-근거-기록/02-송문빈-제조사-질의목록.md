## 답변 후 바로 바뀌는 설계
- Raw ADC 가능 → RDK 방식으로 Range/Doppler/Angle feature 생성 branch 활성화
- Intermediate Map 가능 → AI feature extraction 단순화
- Timestamp/Sync 가능 → Hardware-aligned Fusion
- Target only → Target-level Fusion을 제품 기준으로 Freeze
- 10 Hz 고정 → Tracker prediction 비중 증가
- FW Update/Recovery 확보 → 샘플 1대에서 staged update 검증
