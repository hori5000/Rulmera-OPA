# AS_613 매뉴얼 확인 근거

출처: **AS_613_AI_User_Manual_v.2.2_en.pdf**  
현재 프로젝트에서는 송문빈 대표/인지니어스가 제공하는 실제 샘플 및 자료와 대조 확인한다.

## 현재 확인한 핵심
- 통합 60 GHz multi-channel FMCW radar/software solution
- GPIO / UART / USB
- Wall / Ceiling position mode
- 좌표 및 Detection ROI/Angle 설정
- `walltilt` 0~45° 보정
- `op` setting이 Signal Processing Grid/Capon Map의 axis 선택과 관련
- 처리된 Target output 중심
- 최대 5 target 수준 기술
- 통상 약 10 Hz 수준 기술
- Phantom object, moving object false detection, nearby people merge, stationary fluctuation 가능성 경고

## 2026-09-16 추가 확인
매뉴얼 자체에는 정확한 MMIC가 명시되지 않았지만 별도 확인을 통해 **AS_613 내부 MMIC는 Infineon BGT60TR13C로 확인**되었다.

BGT60TR13C의 공식 센서 구조는 Rx별 **Real IF ADC**이며 직접 I/Q pair를 출력하지 않는다. 따라서 과거 문서의 `Raw IQ` 표현은 `Raw ADC / Real IF`로 정정한다.

## 해석
이 매뉴얼만으로는 Rulmera가 Raw ADC를 직접 받는다고 볼 수 없다. AS_613 내부에서 Capon/Grid 계열 처리를 수행하고 상위에서는 좌표 등 처리 결과를 사용하는 구조로 읽히는 편이 자연스럽다.

다만 BGT60TR13C + Infineon RDK 자체는 Raw frame과 Range/Doppler/Angle 처리가 가능하므로, 실제 질문은 **AS_613 Library/API에서 어느 수준까지 노출하는지**이다.
