# AS_613 매뉴얼 확인 근거

출처: **AS_613_AI_User_Manual_v.2.2_en.pdf**  
현재 프로젝트에서는 송문빈 대표/인지니어스가 제공하는 실제 샘플 및 자료와 대조 확인한다.

## 현재 확인한 핵심
- 통합 60 GHz multi-channel FMCW radar/software solution
- GPIO / UART / USB
- Wall / Ceiling position mode
- 좌표 및 Detection ROI/Angle 설정
- `walltilt` 0~45° 보정
- `op` setting이 Signal Processing Grid/Capon Map의 axis 선택과 관련
- 처리된 Target output 중심
- 최대 5 target 수준 기술
- 통상 약 10 Hz 수준 기술
- Phantom object, moving object false detection, nearby people merge, stationary fluctuation 가능성 경고

## 해석
이 자료만으로는 Rulmera가 Raw IQ를 받아 직접 Capon을 계산한다고 볼 수 없다. 오히려 Capon/Grid 처리가 모듈 내부 신호처리에 포함되고 상위에서는 좌표 등 처리 결과를 사용하는 구조로 읽히는 편이 자연스럽다.

## 아직 이 문서만으로 알 수 없는 것
- MMIC exact part number
- Infineon SDK/library exact name/version
- Raw IQ/ADC export
- Range-Doppler export
- Detection point export
- Capon/Angle grid raw export
- HW sync/trigger
- multi-module interference handling
