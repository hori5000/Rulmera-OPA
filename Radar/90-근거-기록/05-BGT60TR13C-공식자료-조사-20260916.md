# BGT60TR13C 공식자료 / Library 조사

조사일: 2026-09-16  
목적: AS_613 내부 MMIC가 **Infineon BGT60TR13C**로 확인된 이후, 공식 센서 사양·Radar Development Kit·Library 기능·펌웨어 경계를 기술 기준선으로 반영한다.

## 1. 확정 사양
Infineon 공식 제품/데이터시트 기준:
- XENSIV™ BGT60TR13C
- 60 GHz FMCW
- 58.0~63.5 GHz
- 1Tx / 3Rx
- Antennas-in-Package
- 3 ADC channels, 12-bit, up to 4 MSps
- SPI configuration
- FSM/FIFO 내장

공식:
- https://www.infineon.com/part/BGT60TR13C
- https://www.infineon.com/assets/row/public/documents/24/49/infineon-bgt60tr13c-datasheet-en.pdf

## 2. Raw Data 중요한 정정
BGT60TR13C의 Rx baseband는 **Real IF**이다.

즉:
```text
Rx1: Real IF samples
Rx2: Real IF samples
Rx3: Real IF samples
```

센서가 각 Rx에 대해 직접 `I + Q` 두 스트림을 주는 방식이 아니다.

FFT를 수행하면 각 주파수 bin의 complex spectrum과 phase를 얻을 수 있고 이를 angle/doppler 처리에 활용한다.

관련 Infineon Developer Community 답변:
- https://community.infineon.com/t5/Radar-sensors/Question-about-Raw-Data-of-the-BGT60TR13C-kit/td-p/331468
- https://community.infineon.com/t5/Radar-sensors/BGT60TR13C-ADC-FIFO-control/td-p/379913

## 3. Radar Development Kit 기능
공식 DEMO-BGT60TR13C는 Radar Baseboard MCU7와 함께 RDK/Radar Fusion GUI를 지원한다.

공식 평가보드:
- https://www.infineon.com/evaluation-board/DEMO-BGT60TR13C

확인된 기능:
- Radar configuration
- Raw time-domain data
- Range
- Velocity
- Angle
- Range Spectrum
- Range-Doppler
- Range-Angle / Digital Beamforming
- Presence detection
- Segmentation / tracking 계열 기능

RDK는 C/C++, Python, MATLAB 개발 경로를 제공한다.

2026년에도 BGT60TR13C FMCW Python API는 `ifxradarsdk.fmcw.DeviceFmcw` 계열이 사용되고 있다.

## 5. Raw frame API 조사
현재 RDK 계열 C API 예에서는:
```text
ifx_fmcw_get_next_raw_frame(fmcw_device, frame)
```
계열이 사용된다.

구 Avian 예제/호환 계층에서는:
```text
ifx_avian_get_next_frame(device_handle, frame)
```
가 확인된다.

Python 계열에서는:
```python
from ifxradarsdk.fmcw import DeviceFmcw
```
를 사용하고 `device.get_next_frame()` 계열로 frame을 획득하는 예제가 존재한다.

장치 열거/버전 확인에는 `DeviceFmcw.get_list()` 및 `get_version_full()` 계열이 확인된다.

BGT60TR13C raw data 획득이 칩/공식 개발환경에서는 가능하므로, 앞으로의 제조사 질문은:
> “Raw가 존재하느냐?”가 아니라 “AS_613 API에서 외부로 노출하느냐?”
로 바꾼다.

## 6. Range / Doppler / Angle
Infineon BGT60TR13C Digital Beamforming Application Note에서:
- time-domain data fetch
- Range processing
- Doppler processing
- DBF angle processing
- Range-Angle map
경로가 설명된다.

공식 Application Note:
- https://www.infineon.com/dgdl/Infineon-AN652_Digital_Beamforming_using_the_BGT60TR13C_Radar_Sensor-ApplicationNotes-v01_40-EN.pdf

이 기능들은 AI의 직접 입력이 아니라 먼저 **물리 Feature Generator**로 활용하는 것이 권장된다.

## 7. Capon
과거 RDK에는 AngleCapon 함수/라이브러리 계열이 존재하며, BGT60TR13C의 3Rx 입력으로 각도 Spectrum을 생성하는 개발 경로가 확인된다.

다만 AS_613 매뉴얼의 `Capon Map`과 Infineon SDK의 AngleCapon이 정확히 같은 설정/배열/출력을 의미하는지는 공급 Library를 받아 비교해야 한다.

## 8. 펌웨어 경계
### Infineon DEMO-BGT60TR13C
Radar Baseboard MCU7 FW는:
- Host PC와 USB 통신
- BGT60TR13C register read/write
- SPI raw data read
- Sensor board identify
를 수행하며 기본 FW 자체는 신호처리를 수행하지 않는 Reference Bridge 성격이다.

RDK/Radar Fusion GUI에서는 MCU7 FW를 플래시할 수 있다.

관련:
- https://community.infineon.com/t5/Radar-sensors/DEMO-BGT60TR13C-processing-on-radar-baseboard/td-p/945138
- https://community.infineon.com/t5/Radar-sensors/Programing-MCU7-Baseboard/td-p/693083

### AS_613
AS_613는 인지니어스 제품이므로:
- Host MCU
- Bootloader
- FW image
- Update interface
- Recovery
- Rollback
을 **다시 확인해야 한다**.

MCU7 FW는 참고 자료이며 AS_613용 FW라고 간주하지 않는다.

## 9. 샘플 4대 반영
송문빈 대표가 샘플 4개를 보내주기로 한 상태를 기준선에 반영한다.

입고 후:
```text
R01
R02
R03
R04
```
로 고정 관리하고 HW/FW/SDK Revision matrix를 작성한다.
