# AS_613 AI User Manual v2.2 학습데이터 적합성

## 결론

AS_613 매뉴얼의 데이터는 **완성 센서 연동·기능 검증·Benchmark에는 유용**하지만, BGT60TR13C 원신호 기반 독자 AI 학습의 주 데이터로는 부족하다.

| 매뉴얼 데이터 | 활용 판단 | Rulmera 용도 |
|---|---|---|
| X/Y/Z 좌표 / 거리 | 보조 가능 | Tracking Benchmark, 검증 |
| Energy | 보조 가능 | 결과 비교용 Feature |
| Heart Rate / Breathing Rate | 보조 가능 | 업체 결과 Benchmark |
| Heart pulse 0/1 | 보조 가능 | 이벤트 비교 |
| Breathing waveform 0~999 | 제한적 | 가공 파형 비교. Raw 대체 불가 |
| HRV RMSSD / SDNN | 보조 가능 | 검증 결과 |
| Fall / occupancy / patient status | 입력 금지(동일 과제) | Benchmark/Weak Label |
| ROI / sensitivity / rotate / walltilt | 메타데이터 | 시험조건 기록 |
| `op` Capon map channel 선택 | 학습데이터 아님 | 내부 처리 존재 확인용 |
| USB/UART ASCII packet | 결과 수집에 적합 | AS_613 Benchmark logger |

## 매뉴얼에서 확인된 출력 구조

- USB는 CDC 가상 COM으로 동작하며 UART와 같은 command/response 형식을 사용한다.
- 위치 모드에서는 좌표/거리/Energy 등의 ASCII 결과를 출력한다.
- Vital 모드에서는 HR, BR, 거리, 상태, 옵션에 따라 가공된 waveform/HRV 등을 출력한다.
- 매뉴얼에는 Raw ADC frame, RX별 ADC stream, Range-Doppler Map, Capon Map array의 외부 출력 규격이 정의되어 있지 않다.

## 활용 원칙

AS_613 4대가 제공되면 다음 용도로 사용한다.

```text
동일 실험
  ├─ AS_613 → 기존 제품 결과
  └─ Rulmera Raw Pipeline → Raw/DSP/AI 결과
                         ↓
                  동일 Ground Truth에서 비교
```
