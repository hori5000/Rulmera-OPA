# BGT60TR13C + PSoC 6 기술 기준선

## 1. 확정 구성

- Radar MMIC: **Infineon BGT60TR13C**
- BGT60TR13C 기본 구조: 1 TX / 3 RX
- BGT60TR13C Radar Data: RX IF를 12-bit ADC로 샘플링하여 FIFO에 저장
- 신호 성격: **real IF**
- Host MCU 기준: **PSoC 6**
- PoC 후보 보드: **KIT_CSK_BGT60TR13C**
- 학습 서버: NVIDIA A6000 사용

## 2. 중요한 해석

### Raw와 I/Q를 구분한다

BGT60TR13C에서 native Q 채널이 없다는 사실은 Raw 데이터가 없다는 뜻이 아니다.

```text
RX1/RX2/RX3 real IF
        ↓
12-bit ADC
        ↓
FIFO
        ↓
Raw frame
        ↓
FFT
        ↓
복소 스펙트럼 / 위상정보
```

따라서 Rulmera Radar에서 말하는 **Raw**는 우선 RX별 ADC(real IF) sample/frame을 의미한다.

## 3. 독립개발 원칙

1. 기존 AS_613 내부 펌웨어 소스가 없어도 독립개발을 진행할 수 있어야 한다.
2. Infineon 공식 데이터시트/SDK/라이브러리와 개발키트 기반으로 재현 가능한 구조를 만든다.
3. 업체 고유 결과값은 비교 기준으로만 관리하고, Rulmera의 원본 학습 데이터는 별도로 구축한다.
4. PC Reference Engine에서 충분히 검증한 뒤 Edge/MCU 이관 범위를 결정한다.

## 4. PoC 성공 정의

다음이 모두 확인되면 1차 PoC 성공으로 본다.

- PSoC 6에서 BGT60TR13C 초기화
- SPI 통신 및 상태 읽기
- Frame completion IRQ 동작
- FIFO Raw frame 연속 취득
- RX 채널별 frame 구조 검증
- Frame counter / timestamp 부여
- PC로 안정적 전송
- PC 저장 후 Range FFT 재현
- Range-Doppler 계산
- 다중 RX 기반 Angle/Phase 처리 검증
- A6000 학습 파이프라인 입력까지 연결

## 5. 최종 PCB 방향

PoC 이후 자체 PCB에서는 개발키트에 포함된 부가 기능을 그대로 복제하지 않는다.

최소 구성 후보:

```text
BGT60TR13C
 + Host MCU
 + Radar clock / power
 + USB 또는 고속 통신
 + SWDIO / SWDCLK / XRES / VREF / GND test pads
```

실제 MCU와 인터페이스는 Raw bandwidth 및 Edge 모델 요구성능 계측 후 확정한다.
