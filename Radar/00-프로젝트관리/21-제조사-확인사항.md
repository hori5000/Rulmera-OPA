## 답변을 받을 때 함께 확보할 것
- AS_613 4개 Serial / PCB Rev / Host MCU
- PDF/매뉴얼 원본
- SDK/Library 전체 패키지
- Header/API 문서
- 샘플 코드
- FW binary + version string
- **Firmware Update Tool/Script + Driver**
- **Recovery/Bootloader 절차**
- 실제 UART/USB Raw Log 1개
- Raw ADC 가능 시 1 frame dump와 배열 차원 설명
- 설정 명령 목록
- 가능하면 1/2/4 Sensor 동시 구동 권장 방식

## 펌웨어 주의
Infineon DEMO-BGT60TR13C의 Radar Baseboard MCU7는 RDK/Radar Fusion GUI로 플래시할 수 있지만 이것은 **Infineon 평가보드 기준**이다. AS_613 업데이트 절차는 인지니어스 전용 구조를 다시 확인한 뒤 문서화한다.
