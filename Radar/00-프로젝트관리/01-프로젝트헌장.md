# 프로젝트헌장

## 추진 배경·필요성
단일 레이더 모듈은 설치 방향, 사각, 반사, 벽·가구, 다중 객체 겹침 때문에 공간 전체를 안정적으로 이해하기 어렵다. Rulmera Radar는 복수의 상용/공급 레이더 모듈을 Rulmera가 설계한 하나의 Radar Node로 통합하여 공간 좌표계에서 객체를 추적하고, 방 구조와 반사를 학습/보정하는 시스템을 목표로 한다.

## 목적
- **Infineon BGT60TR13C 기반 AS_613** 복수 센서를 천장형 Node로 통합
- 센서별 좌표를 공통 좌표계로 정합
- Multi Radar Fusion과 Tracking 구현
- Room Mapping / Wall Mask / Ghost 제거 구현
- AI 기반 신뢰도 및 Track 보정
- PC 기준 구현을 Edge Hub로 이관 가능한 제품 구조 확립

## 측정 가능한 성공기준

| 목표 | 측정지표 | 초기 목표값 | 확인방법 |
|---|---|---:|---|
| 4 Radar 동시 수집 | 동시 연결/로그 성공 | 4/4 | 장시간 수집 시험 |
| 좌표 정합 | 기준 위치 오차 | 시험 후 Freeze | 정적 기준점 측정 |
| 추적 지속성 | Track 유지율/ID Switch | 시험 후 Freeze | 동선 시나리오 |
| Ghost 억제 | 오검출 감소율 | Baseline 대비 개선 | 반사 환경 A/B 시험 |
| Room Mask | 벽 밖 Target 억제 | 정상 공간 내 오검출 최소화 | 벽/문/코너 시험 |
| Edge 이관 | PC 대비 기능 동등성 | 핵심 기능 동일 | Replay 결과 비교 |

> 수치 목표는 실제 AS_613 출력 주기와 데이터 수준을 확인한 뒤 시험 기준선에서 Freeze한다.

## 예산·자원 한계
- Rulmera 측 전체 개발의 주 책임자는 윤석훈
- 레이더 모듈 및 관련 자료는 인지니어스/송문빈 대표 공급을 기준으로 함
- **샘플 4개 공급 예정은 확인**
- SDK 제공 조건, 라이선스 조건, Raw ADC 노출 범위는 별도 확인 필요

## 주요 위험·가정·제약조건
- BGT60TR13C 자체는 Raw ADC가 가능하나 AS_613 API가 Low-level 데이터를 제한할 수 있음
- 10 Hz 수준의 Target 출력만 제공될 경우 고속 동작 추적에 한계 가능
- 모듈 간 하드웨어 Sync 부재 가능
- 다중 레이더 상호 간섭 가능성 확인 필요
- 공급 펌웨어와 매뉴얼/Library 버전 불일치 가능
- 복수 사람 근접 시 Target Merge 가능
- AS_613 FW update/recovery 경로 미확정 상태에서 임의 플래시는 금지

## 프로젝트관리자 권한
윤석훈은 Rulmera Radar의 범위, 기술 아키텍처, 우선순위, 소프트웨어/AI 구현, Hub 설계 및 Rulmera 내부 기준선 승인 권한을 가진다. 레이더 모듈 내부 기능/변경은 인지니어스와 협의한다.
