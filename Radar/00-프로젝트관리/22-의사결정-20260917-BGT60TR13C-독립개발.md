# BGT60TR13C 독립개발 의사결정 기준선

## 결정 요약

| ID | 결정 | 상태 |
|---|---|---|
| DEC-RADAR-20260917-01 | 레이더 MMIC 기준 부품은 **Infineon BGT60TR13C**로 확정한다. | 확정 |
| DEC-RADAR-20260917-02 | 현재 AS_613 계열의 Host MCU는 **PSoC 6**로 확인되었다. 정확한 PSoC 6 Part Number는 별도 확인 항목으로 둔다. | 확정/세부확인 |
| DEC-RADAR-20260917-03 | 기존 AS_613 펌웨어의 Lock/내부 구현에 Rulmera Radar 핵심 개발 일정을 의존하지 않는다. | 확정 |
| DEC-RADAR-20260917-04 | AS_613 샘플은 **기존 알고리즘의 기능·성능 Benchmark 장비**로 사용한다. | 확정 |
| DEC-RADAR-20260917-05 | 신규 AI 학습의 원본 기준은 **BGT60TR13C RX별 Raw ADC(real IF) frame**으로 한다. | 확정 |
| DEC-RADAR-20260917-06 | BGT60TR13C는 native I/Q pair가 아니라 **real IF**를 제공하므로 Q 채널 부재를 Raw 데이터 부재로 해석하지 않는다. | 확정 |
| DEC-RADAR-20260917-07 | Raw는 영구 보존하고, Range/Doppler/Angle/Capon/Micro-Doppler 및 수치 Feature를 파생 계층으로 생성한다. | 확정 |
| DEC-RADAR-20260917-08 | 기존 업체가 계산한 낙상/생체/상태 결과는 동일 과제 AI의 입력 Feature로 쓰지 않고 Benchmark/검증/보조 Label로 분리한다. | 확정 |
| DEC-RADAR-20260917-09 | PoC는 **KIT_CSK_BGT60TR13C + PSoC 6** 경로를 우선한다. PSoC 6에서 Radar FIFO를 읽어 PC로 전송하는 Raw Bridge를 직접 개발한다. | 현재 기준선 |
| DEC-RADAR-20260917-10 | PoC 1대로 Raw → PC → 신호처리 → A6000 학습 경로를 검증한 뒤 다중 보드 또는 자체 PCB로 확대한다. | 현재 기준선 |
| DEC-RADAR-20260917-11 | 최종 MCU/PCB는 먼저 고정하지 않고, 실제 신호처리·AI 계산량과 통신량을 계측한 뒤 선정한다. | 확정 |
| DEC-RADAR-20260917-12 | 사용자에게 전달하는 Radar 마이그레이션 산출물에서 **90-PUBLIC은 항상 제외**한다. | 확정 |

## 개발의 기준 흐름

```text
BGT60TR13C
  ↓ SPI / IRQ / FIFO
PSoC 6
  ↓
Rulmera Raw Bridge Firmware
  ├─ RX별 Raw ADC(real IF) frame 취득
  ├─ Frame counter / timestamp
  ├─ Radar configuration snapshot
  ├─ overflow / drop 상태 기록
  └─ PC streaming
        ↓
PC Recorder
  ├─ L0 Raw 보존
  ├─ L1 Signal/Map 생성
  └─ L2 Feature 생성
        ↓
A6000
  ↓
AI 학습 / 비교 / 검증
        ↓
최종 Edge 요구성능 산정
        ↓
자체 PCB / MCU / Firmware 이관
```

## 현재 미확정 항목

- AS_613에 사용된 PSoC 6의 정확한 Part Number
- AS_613 기존 PCB의 erase/program 가능 여부
- AS_613 기존 펌웨어의 실제 빌드 툴체인
- AS_613 내부에서 Raw ADC를 외부로 내보내는 기능의 존재 여부

위 항목은 **Rulmera 독립개발의 선행조건이 아니다.** 제공되면 비교·검증 자료로 활용한다.
