# 품질·인수기준

| 산출물·기능 | 품질·수용기준 | 검증방법 | 승인 |
|---|---|---|---|
| Radar Adapter | 동일 입력을 오류 없이 파싱, 센서 식별 가능 | Raw Log Replay | 윤석훈 |
| 4 Radar Logger | 4개 동시 기록, Drop/지연 측정 가능 | 장시간 로그 | 윤석훈 |
| Calibration | Room 좌표계 변환이 반복 재현됨 | 기준점 시험 | 윤석훈 |
| Fusion | 다중 센서 중복 Target이 Track으로 통합 | Replay/실측 | 윤석훈 |
| Tracking | ID Switch/Drop 지표 산출 가능 | 동선 시나리오 | 윤석훈 |
| Wall Mask | 방 경계 밖 False Target 감소 | 벽/코너 시험 | 윤석훈 |
| Ghost Filter | 반사 환경에서 False Track 감소 | Baseline A/B | 윤석훈 |
| AI Correction | 규칙기반 Baseline보다 최소 1개 핵심 지표 개선 | 동일 Replay A/B | 윤석훈 |
| Edge Port | PC와 같은 로그에 대해 허용오차 내 결과 | PC-vs-Edge Diff | 윤석훈 |

## 공통 품질 원칙
- 결과만 보지 말고 입력 로그와 설정을 함께 보존
- 센서별 FW/설정/설치 Pose를 데이터셋 메타데이터에 기록
- 성능 수치는 시험 시나리오와 함께 기록
- "좋아 보임"이 아니라 재현 가능한 지표로 판단
