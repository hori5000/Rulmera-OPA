# Rulmera Radar 기술 기준선

기준일: 2026-09-15

## 1. 확정된 프로젝트 기준
- Rulmera Radar는 **Rulmera 자체 프로젝트**
- Rulmera 전체 개발 책임: **윤석훈**
- 레이더 모듈 제작사: **인지니어스**
- 인지니어스 오너/대표: **송문빈 대표**
- 모든 레이더 샘플과 기본 기술자료 공급 창구: **송문빈 대표**
- 이해관계자는 계속 추가 가능

## 2. 현재 제품 기준
- Radar: **AS_613 ×4 / 천장형 Radar Node 1개 기준**
- 상대 방위각: **약 90도 간격 후보**
- 하향각: **약 45도 후보**
- 실제 설치각: 실측 후 Freeze
- 큰 공간: Radar Node 추가
- 목표: 360도 감지 / Multi Radar Fusion / Tracking / Room Mapping / 자동 Wall Mask / Ghost·Noise 제거 / AI 보정
- PC 개발/학습: RTX 3060 또는 A6000
- Edge: Hub MCU 경량 추론
- Hub PCB/MCU: 신규 설계
- PSoC Edge E84: 후보, 미확정

## 3. AS_613 매뉴얼 기반 확인사항
- 60 GHz FMCW 통합 레이더 솔루션
- GPIO/UART/USB 인터페이스
- Wall/Ceiling 설치 모드
- 좌표/ROI/각도 설정
- Wall tilt 0~45° 보정
- `op` 설정이 Signal Processing Grid/Capon Map 축 선택과 연결
- 최대 약 5 Target, 통상 약 10 Hz 수준의 처리된 Target 출력 기술
- 반사 Phantom, 이동 물체 False Detection, 근접 인원 Merge, 정지 Target 흔들림 가능

## 4. 현재 가장 중요한 기술 해석
현재 매뉴얼만 보면 Rulmera 애플리케이션이 IQ를 받아 직접 Capon을 계산하는 구조라기보다 **AS_613 내부 Radar Library/Signal Processing이 Angle/Capon 계열 처리를 하고, 상위 애플리케이션은 처리된 Target 결과를 받는 구조가 더 유력**하다.

그러나 이것은 아직 공급 SDK/API 확인 전이므로 아래를 반드시 구분한다.

### 확정
- 매뉴얼에는 처리된 좌표/Target 출력을 설명함
- `op`는 내부 신호처리 Grid/Capon 축과 관계됨

### 미확정
- 정확한 Infineon MMIC
- Infineon Library 이름/버전
- IQ/Raw ADC 공개 여부
- Range-Doppler 공개 여부
- Detection Point 공개 여부
- Angle/Capon Grid 공개 여부
- SNR/Confidence 필드
- Radar 내부 Timestamp
- HW Trigger/Sync
- 4개 동시 운용 시 간섭 회피 기능

## 6. PC→Edge 원칙
- PC Reference Engine이 기능 정본
- 모든 알고리즘은 저장 로그 Replay 가능
- Edge는 같은 Common Data Contract를 사용
- MCU 선정은 프로파일링 후
- AI는 경량 모델 또는 Rule+ML 혼합으로 이관
