# 명령어 치트시트

## GPU
```bash
nvidia-smi
nvidia-smi --query-gpu=name,memory.total,driver_version,compute_cap --format=csv
watch -n 1 nvidia-smi
```

## WSL
```powershell
wsl --install
wsl --update
wsl --version
wsl -l -v
wsl --shutdown
```

## vLLM
```bash
vllm serve "Qwen/Qwen3.8-27B-FP8"  --served-model-name qwen3.8-27b  --max-model-len 16384  --gpu-memory-utilization 0.88  --max-num-seqs 1
```

## API
```bash
curl http://127.0.0.1:8000/v1/models
```

## Qdrant
```bash
docker compose -f docker-compose.qdrant.yml up -d
curl http://127.0.0.1:6333/collections
```

## RAG

python -m rag_app.vectorstore --init
python -m rag_app.ingest sample_docs --project tutorial
python -m rag_app.retrieve "질문" --project tutorial
