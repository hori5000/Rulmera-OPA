# A6000 성능 튜닝

```text
max_model_len=16384
gpu_memory_utilization=0.88
max_num_seqs=1
embedding=CPU
reranker=OFF
```

## 기록
- first token
- total latency
- output tok/s
- peak VRAM

## 순서
1. gpu-memory-utilization
2. context
3. concurrency
4. embedding GPU
5. reranker

한 번에 하나만 바꾼다.

## 좋은 튜닝과 나쁜 튜닝
좋음:
> 16K→32K만 바꾸고 비교.

나쁨:
> 32K + reranker GPU + concurrency 4 + embedding GPU를 한꺼번에 적용.
