# 보안

## 기본
```text
사용자
→ Reverse Proxy/Auth
→ RAG API
→ localhost vLLM / Qdrant
```

## 외부 공개 금지
- Qdrant 6333/6334
- vLLM 8000

## 문서 ACL
RAG 검색 자체에 권한 filter가 들어가야 한다.
답을 만든 후 가리는 방식은 늦다.

예:
```yaml
acl_groups:
  - water-ai
  - management
```

## Secret
- `.env` Git 제외
- 권한 600
- token을 Obsidian 공유본에 넣지 않음

## 로그
질문/검색문서에 기밀정보가 포함될 수 있다.
운영 로그에 전체 source text를 무조건 남기지 않는다.
