# 용어사전

| 용어 | 설명 |
|---|---|
| LLM | 답을 생성하는 대형 언어모델 |
| Serving | 모델을 API 서버로 계속 띄워두는 것 |
| vLLM | GPU LLM Serving 엔진 |
| OpenAI-compatible | OpenAI SDK와 유사한 REST 형식 |
| Embedding | 텍스트를 의미 벡터로 변환 |
| Vector DB | 유사 벡터를 검색하는 DB |
| Qdrant | 이 프로젝트 Vector DB |
| RAG | 문서를 먼저 검색한 후 LLM에게 근거를 주는 방식 |
| Chunk | 검색을 위해 문서를 나눈 조각 |
| Metadata | 파일/페이지/시트/행 등 부가정보 |
| Retriever | 관련 Chunk를 찾는 모듈 |
| Top-K | 상위 K개 검색 결과 |
| Reranker | 검색 결과 순위를 다시 매기는 모델 |
| Dense | 의미 중심 벡터 검색 |
| Sparse | 키워드/lexical 성격 검색 |
| Hybrid | Dense + Sparse |
| Context | LLM이 요청에서 볼 수 있는 토큰 범위 |
| KV Cache | 이미 처리한 attention 관련 상태를 GPU에 보관하는 메모리 |
| Quantization | 낮은 정밀도로 메모리/연산량을 줄이는 기법 |
| FP8 | 8-bit 부동소수점 |
| Hallucination | 근거 없는 정보를 사실처럼 생성 |
| Citation | 답변 근거 위치 표시 |
| Payload | Qdrant point에 vector와 함께 저장하는 JSON |
| Namespace | 프로젝트/현장별 데이터 논리 분리 |
