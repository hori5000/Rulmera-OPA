## Gate A — 모델
- `nvidia-smi` 정상
- vLLM 기동
- 모델 로딩
- 한국어 질의
- 10회 연속 요청
- VRAM 기록

## Gate B — Retrieval
- 정답 문서가 Top-K에 들어옴
- source locator(page/sheet/row)가 보존됨

## Gate C — RAG
- 좋은 근거를 사용
- `[S1]` 표시
- 실제 source list 반환
- 근거 없을 때 추측 억제

## Gate D — 운영
- 재부팅 자동기동
- snapshot/복구
- 방화벽/ACL
- 평가셋 회귀테스트
