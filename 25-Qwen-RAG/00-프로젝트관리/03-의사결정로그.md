# 의사결정 로그

## ADR-001 — 독립 프로젝트
Qwen-RAG는 `30-기술자료` 하위가 아니라 여러 프로젝트가 사용하는 **독립 플랫폼 프로젝트**다.

## ADR-002 — vLLM
Qwen 공식 모델 카드가 vLLM과 OpenAI 호환 API 사용을 직접 안내하며 모델 교체와 serving 분리가 쉽다.

## ADR-003 — Windows는 WSL2
vLLM의 표준 OS는 Linux이며 Windows에서는 WSL2를 사용한다. community Windows fork는 주 구축 경로로 쓰지 않는다.

## ADR-004 — Qdrant
Docker 기동이 간단하고 payload/filter/hybrid 확장이 가능하다.

## ADR-005 — Embedding 0.6B 우선
`Qwen3-Embedding-0.6B`는 최대 1024 dimension, 32K context, 다국어를 지원한다. 본 LLM과 GPU 경합을 피하기 위해 최초에는 CPU로 둔다.

## ADR-006 — Reranker는 나중
Dense retrieval baseline을 먼저 측정한 뒤 `Qwen3-Reranker-0.6B` 효과를 비교한다.

## ADR-007 — venv 분리
```text
.venv-llm
.venv-rag
```
CUDA/PyTorch 의존성이 강한 vLLM과 parser/embedding 환경을 분리해 업데이트 충돌을 줄인다.

## ADR-008 — 출처추적 우선
답변을 그럴듯하게 만드는 것보다 evidence를 원문 위치까지 추적할 수 있게 하는 것이 우선이다.
