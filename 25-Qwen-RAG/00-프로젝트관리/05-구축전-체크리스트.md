# 구축 전 체크리스트

## 하드웨어
- [ ] NVIDIA GPU
- [ ] RTX A6000 48GB 확인
- [ ] GPU 점유 프로세스 확인
- [ ] RAM 32GB 이상, 가능하면 64GB+
- [ ] SSD 여유 100GB+ 권장

## Windows
- [ ] NVIDIA Windows Driver
- [ ] WSL2
- [ ] Ubuntu
- [ ] WSL 내부 `nvidia-smi`
- [ ] Docker Desktop 또는 WSL Docker 중 하나 선택

## Linux
- [ ] Ubuntu
- [ ] NVIDIA driver
- [ ] `nvidia-smi`
- [ ] Python 3.10~3.13
- [ ] Docker
- [ ] GPU Docker를 쓸 경우 NVIDIA Container Toolkit

## 포트
| 포트 | 용도 | 기본 공개 |
|---:|---|---|
| 8000 | vLLM | localhost/내부망 |
| 8100 | RAG API | localhost/내부망 |
| 6333 | Qdrant REST/UI | localhost |
| 6334 | Qdrant gRPC | localhost |

## 버전 기록
```bash
nvidia-smi
python --version
vllm --version
docker --version
docker compose version
```
업데이트 후 장애의 절반은 “무슨 버전이었는지 모름” 때문에 복구가 늦어진다.
