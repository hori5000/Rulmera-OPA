# 문서 수집 및 정규화

## 우선 형식
1. Markdown
2. PDF
3. DOCX
4. XLSX
5. CSV/TXT

## Chunk 기준
단순 글자 수보다 문서 구조를 우선한다.

1. Heading
2. 표
3. 의미 단위
4. 길이 제한

## Excel 중요사항
Excel은 평문으로만 풀지 않는다.

보존할 것:
- Sheet
- Row
- Column
- Cell range
- Header
- 병합셀
- 계층번호
- 원본경로

## PDF
텍스트 레이어 우선.
OCR은 텍스트가 없는 경우만 사용.
페이지 번호를 반드시 보존한다.
