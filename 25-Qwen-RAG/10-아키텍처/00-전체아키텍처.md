# 전체 아키텍처

## 적재 흐름
```text
원본
→ SHA-256
→ Parser
→ SourceBlock
→ Chunk
→ Embedding
→ Qdrant(Point + Vector + Payload)
```

## 질의 흐름
```text
Question
→ Query Embedding
→ Qdrant Filter + Top-K
→ Optional Reranker
→ Context Builder
→ vLLM / Qwen
→ Answer + Sources
```

## 왜 LLM과 RAG를 분리하는가
LLM을 Qwen에서 다른 모델로 바꾸어도 Vector DB와 parser는 재사용할 수 있어야 한다.

## 왜 원본과 Qdrant를 분리하는가
Qdrant는 원본 보관소가 아니다. citation이 실제 원문으로 이어지려면 원본은 별도로 보존해야 한다.
