# 하드웨어 / 용량 산정

## Weight 크기와 VRAM 요구량은 같지 않다
GPU에는 다음이 동시에 올라간다.

```text
Weight
+ runtime buffers
+ vision encoder
+ CUDA/compile workspace
+ KV cache
+ batch/concurrency
+ framework overhead
```

따라서 “27B FP8 = 27GB” 식 단순 계산으로 운영 가능성을 판정하지 않는다.

## Context의 영향
Context가 증가할수록 KV cache 요구량이 커진다.
262K를 지원하는 모델이라고 해서 A6000 1장에서 262K를 실용적으로 쓰라는 뜻은 아니다.

## A6000 48GB 기준선
- 16K
- max-num-seqs=1
- gpu-memory-utilization=0.88
- Embedding=CPU
- Reranker=OFF

성공 후:
1. 32K
2. 동시성 2
3. Embedding GPU
4. Reranker
순서로 하나씩 시험한다.

## RAM
32GB가 최소 실험선, 대형 PDF/XLSX와 다중 parser 작업을 생각하면 64GB+가 편하다.

## 저장공간
모델 cache, compile cache, Qdrant, 원본, 백업을 합쳐 개발 서버라도 100GB+ 여유를 권장한다.
