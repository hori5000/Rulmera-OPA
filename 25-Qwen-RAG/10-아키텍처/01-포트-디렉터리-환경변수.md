# 포트 / 디렉터리 / 환경변수 표준

## Linux/WSL 권장
```text
~/qwen-rag/
├─ llm/
├─ rag/
├─ data/
│  ├─ incoming/
│  ├─ originals/
│  └─ processed/
├─ logs/
└─ backups/
```

## Windows
모델 캐시/venv는 `/mnt/c`보다 WSL Linux filesystem의 `/home/...`에 두는 것이 일반적으로 관리하기 편하다.

## 서비스
```text
vLLM        127.0.0.1:8000
RAG API     127.0.0.1:8100
Qdrant REST 127.0.0.1:6333
Qdrant gRPC 127.0.0.1:6334
```
