# A6000 / FP8 주의사항

## 핵심
RTX A6000은 Ampere 계열이다.

“FP8 체크포인트”라는 말과 “GPU가 최신 FP8 W8A8 연산을 네이티브 Tensor Core로 최고 효율 처리”한다는 말은 동일하지 않다.

vLLM은 최신 버전에서 Ampere에 대해 Marlin 계열 FP8/weight-only 경로를 지원할 수 있지만, 일반적인 FP8 W8A8 경로와 하드웨어 지원표는 다르게 봐야 한다.

## 우리 판정법
문서상 가능 여부가 아니라 **실제 기동**을 판정한다.

### PASS
- 모델 로드
- kernel error 없음
- 10회 연속 요청
- VRAM 안정
- throughput 측정

### 문제가 생기면
1. 최신 stable vLLM 확인
2. 16K→8K
3. `0.88→0.84`
4. `--max-num-seqs 1`
5. CUDA graph 문제는 `--enforce-eager`
6. FP8 backend 문제면 A6000 친화적 AWQ/GPTQ 등 다른 체크포인트 비교

## 중요한 결론
A6000에서도 “일단 시도”는 합리적이지만, FP8 이름만 보고 native FP8 성능을 가정하지 않는다.
