# 멀티모달 RAG

Qwen3.8-27B는 vision encoder를 포함한 멀티모달 모델이다.

## 1차
텍스트 RAG를 완성한다.

## 2차
PDF page에서:
- 공정도
- P&ID
- PLC 구조도
- 그래프
- 스크린샷
을 이미지로 활용.

## 실용적인 1차 멀티모달 방식
1. PDF text로 관련 page 검색
2. 검색된 page를 이미지 렌더링
3. 해당 page image + 질문을 Qwen에 전달

모든 이미지를 별도 vision vector DB로 만드는 것보다 단순하다.

## A6000 주의
이미지 입력은 VRAM/latency를 추가한다.
텍스트 RAG 안정화 후 적용.
