# 증분 인덱싱 / 중복 관리

## exact duplicate
파일 SHA-256가 같으면 skip 가능.

## 같은 논리문서 신버전
- canonical key 동일
- hash 변경

정책:
- 이전 `is_current=false`
- 신규 `is_current=true`

## 왜 중요
동일 WBS의 여러 날짜본이 모두 Top-K에 뜨면 AI가 서로 다른 상태를 섞는다.

## 운영 manifest
추천 필드:
```text
canonical_id
source_path
source_hash
indexed_at
point_count
version
is_current
```

초기에는 JSON/SQLite, 이후 Postgres 등.

## 삭제 reconcile
원본에서 삭제됐다고 Qdrant에서 자동 삭제되지 않는다.
정기적으로 원본 inventory와 vector inventory를 비교한다.
