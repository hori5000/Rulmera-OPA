# Windows — WSL2 설치

## 1. 관리자 PowerShell
```powershell
wsl --install
```

필요하면 재부팅.

## 2. 업데이트
```powershell
wsl --update
wsl --version
wsl -l -v
```

정상:
```text
NAME      STATE    VERSION
Ubuntu    Running  2
```

VERSION=1이면:
```powershell
wsl --set-version Ubuntu 2
```

## 3. Ubuntu
Ubuntu를 실행해 사용자/비밀번호를 만든다.

```bash
sudo apt update
sudo apt upgrade -y
sudo apt install -y git curl wget ca-certificates build-essential python3 python3-venv python3-pip
```

## 4. GPU
```bash
nvidia-smi
```

Windows GPU가 보여야 한다.

## 5. 하지 말 것
```bash
sudo apt install nvidia-driver-XXX
```
를 WSL에서 해결책으로 실행하지 않는다.

## 6. WSL RAM 제한(선택)
Windows 사용자 홈 `.wslconfig` 예:
```ini
[wsl2]
memory=48GB
processors=8
swap=16GB
```

적용:
```powershell
wsl --shutdown
```
호스트 RAM에 맞게 조절한다.
