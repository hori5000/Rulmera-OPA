# 템플릿 사용안내

## 두 종류의 문서

- `프로젝트관리`: 프로젝트마다 한 벌씩 생성하여 계속 갱신하는 기준선·등록부
- `기록-양식`: 회의, 의사결정, 문제, 기술 검토가 생길 때마다 새 문서로 만드는 양식

## 기록 연결 원칙

회의에서 나온 결과는 회의록에만 남겨두지 않습니다.

| 회의 결과 | 함께 갱신할 문서 |
|---|---|
| 새 할 일 | 액션아이템로그 |
| 새 위험 | 리스크등록부 |
| 발생한 문제 | 이슈로그 + 상세 문제해결 문서 |
| 확정한 판단 | 의사결정로그 + 상세 의사결정 문서 |
| 범위·일정·비용 변경 | 변경요청 + 변경로그 |
| 새 요구사항 | 요구사항추적표 |

## OpenProject 연결

각 프로젝트의 `00-프로젝트관리/00-OpenProject-연결.md`에 프로젝트 홈, WBS, 간트, 마일스톤 등 저장된 보기 주소를 등록합니다. 개별 문서에는 관련 작업패키지 주소를 추가합니다.
